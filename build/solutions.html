All 35 problem types that carry the 7-mark parts, across both options in every unit — Q1 and Q2, Q3 and Q4, Q5 and Q6, Q7 and Q8, Q9 and Q10. Nothing here depends on which question you end up answering.

How each entry is laid out: METHOD the recipe, in steps · WORKED one full example, taken from a real paper wherever one exists · TRAP what actually loses marks.

UNIT I  —  Q1 and Q2

1   Newton-Raphson — system of two non-linear equations 4× Q1(c)

Method

For f(x,y)=0, g(x,y)=0: at each step solve the linear system J·[Δx, Δy]ᵀ = −[f, g]ᵀ where J = [[fₓ, fᵧ],[gₓ, gᵧ]], then update x₋₁ = x + Δx, y₋₁ = y + Δy. Evaluate J at the current point every iteration.

Worked — M23 1(c) / M24 1(c) / MAM24 1(b)

Solve x²+y²=x, x²−y²=y from (0.8, 0.4), two iterations.

Write f = x²+y²−x, g = x²−y²−y. Then J = [[2x−1, 2y],[2x, −2y−1]].

Trap

At the start point f = 0 exactly — students assume they have made an error and stop. They have not: g ≠ 0, so the iteration still moves. Also, P26 writes the same system as x = x²+y², y = x²−y² — identical, just rearranged.

2   Newton-Raphson — single equation 3× Q2(b)/(c)

Method

x₋₁ = xₙ − f(xₙ)/f′(xₙ). First locate the root by sign change — tabulate f at a few integers and find where it flips sign. Start inside that bracket. Iterate to three decimals.

Worked — M24 2(b) / P26 2(c)

Find a negative root of x eₓ − sin x = 0 to three decimals.

x−0.5−1−2−2.9−3.0−3.5
f(x)+0.176+0.474+0.639+0.080−0.008−0.456

Sign change in (−3.0, −2.9). With f′ = eₓ + x eₓ − cos x and x₀ = −3:

x₁ = −2.990745 → x₂ = −2.990735 → converged.   root = −2.991

Trap — this one is nasty

x = 0 is itself a root of this equation. Start anywhere near zero (−0.5, −1) and Newton-Raphson slides straight back to 0, which is not negative — you get 0.000 and lose the question. You must bracket first. The first genuine negative root is near −3.

3   Taylor / Maclaurin expansion — two variables 4× Q2(c)

Method

f(x,y) = f(a,b) + [h fₓ + k fᵧ] + (1/2!)[h²fₓₓ + 2hk fₓᵧ + k²fᵧᵧ] + …  with h = x−a, k = y−b. Compute the five partials, evaluate all at (a,b), substitute.

Worked — M23 2(c): expand xy + cos(xy) about (1, π/2)

At (1, π/2) we have xy = π/2, so sin(xy) = 1 and cos(xy) = 0.

expressionvalue at (1, π/2)

fₓy(1 − sin xy)0
fᵧx(1 − sin xy)0
fₓₓ−y² cos xy0
fₓᵧ1 − sin xy − xy cos xy0
fᵧᵧ−x² cos xy0

Every term vanishes. To second degree, f(x,y) = π/2.

Trap — do not panic and do not "fix" it

For the cos version the answer really is just π/2. Students get zeros, assume they have blundered, and waste ten minutes. Write the table, state that all first and second derivatives vanish at the point, conclude f ≈ π/2. Full marks.
The other two variants are NOT trivial — know them:
• xy + sin(xy): f = 1+π/2, fₓ = π/2, fᵧ = 1, fₓₓ = −π²/4, fₓᵧ = 1−π/2, fᵧᵧ = −1
• xy² + cos(xy): f = π²/4, fₓ = π(π−2)/4, fᵧ = π−1, fₓₓ = 0, fₓᵧ = π−1, fᵧᵧ = 2

4   Taylor / Maclaurin expansion — one variable 5× Q1(b)

Method

Maclaurin: f(x) = f(0) + x f′(0) + x²f″(0)/2! + …
"In powers of (x−a)" means Taylor about a.
Shortcut for inverse-trig and log forms: differentiate once, expand the resulting rational function as a binomial series, then integrate term by term. Far faster than repeated differentiation.

Worked — MAE23 1(c): Maclaurin series for tan x up to x⁴

f = tan x, f′ = sec²x = 1 + f². Differentiating repeatedly using this identity (much quicker than the quotient rule):

f′ = 1+f², f″ = 2f f′, f′″ = 2f′² + 2f f″, fⁱᵛ = 6f′f″ + 2f f′″

At x=0: f=0, f′=1, f″=0, f′″=2, fⁱᵛ=0

tan x = x + x³/3 + … (the x² and x⁴ terms are zero — tan is odd)

Trap

For an odd function every even-order term vanishes. Say so explicitly rather than leaving gaps — it shows you knew, and it is often worth a mark.

5   Maxima and minima of two variables 5× Q1(d)/Q2(b)

Method — the r-s-t test

  1. Solve fₓ = 0, fᵧ = 0 simultaneously for stationary points.
  2. Set r = fₓₓ, s = fₓᵧ, t = fᵧᵧ.
  3. At each point: rt − s² > 0 and r < 0 → maximum; rt − s² > 0 and r > 0 → minimum; rt − s² < 0 → saddle; = 0 → test fails.

Worked — M23 2(b): x³ + y³ − 3axy

fₓ = 3x² − 3ay = 0, fᵧ = 3y² − 3ax = 0 → stationary points (0,0) and (a,a).

r = 6x, s = −3a, t = 6y, so rt − s² = 36xy − 9a².

  • At (0,0): rt−s² = −9a² < 0 → saddle point
  • At (a,a): rt−s² = 27a² > 0, r = 6a → minimum if a > 0, maximum if a < 0

Trap

The sign of a flips the conclusion — you must split the case, not assume a>0. And (0,0) is a saddle, not "no conclusion": rt−s² is strictly negative.

6   Lagrange multipliers 4× Q1(d)/Q2(d)

Method

To optimise f subject to g = 0: form F = f − λg and solve Fₓ = Fᵧ = Fᵦ = 0 together with g = 0 — four equations, four unknowns. Divide pairs of equations to eliminate λ early; it is almost never wanted.

Worked A — M23 2(d) / MAM24 1(d): open-top box, volume 108 ft³, minimum surface area

Minimise S = xy + 2xz + 2yz subject to xyz = 108.

F = xy + 2xz + 2yz − λ(xyz − 108):

y + 2z = λyz,   x + 2z = λxz,   2x + 2y = λxy

First two give x = y; combining with the third gives x = 2z. Then xyz = 108 → 4z³ = 108 → z = 3.

x = 6, y = 6, z = 3 ft  —  minimum surface area S = 108 ft²

Worked B — M23 1(d): hottest point on the unit sphere, T = 400xyz²

Maximise T on x²+y²+z² = 1. The stationary conditions give x² = y² = z²/2, so x² = y² = 1/4, z² = 1/2.

Highest temperature T = 50, at (±½, ±½, ±1/√2) with xy > 0

Trap

"Open at the top" means one xy face, not two — using 2xy gives a cube and loses the question. And in the sphere problem z appears squared, so z² = 2x², not z² = x².

UNIT II  —  Q3 and Q4

Read this first. The four numerical methods share one skeleton and are far faster learned together than apart. Given y′ = f(x,y), y(x₀) = y₀, step h:
Taylor — differentiate the ODE repeatedly, evaluate at the start point, substitute into the Taylor series. Euler — one slope, at the left end. Modified Euler — average the slopes at both ends, iterating until the value settles. RK4 — a weighted average of four slopes. Same tabulation discipline throughout: carry 4–6 decimals, show every row.

Method

y(x₀+h) = y₀ + h y′₀ + (h²/2!)y″₀ + (h³/3!)y′″₀ + (h⁴/4!)yⁱᵛ₀ + …
Get y″ by differentiating y′ = f(x,y) totally: y″ = fₓ + fᵧ·y′. Repeat. Then evaluate every derivative at the initial point.

9   Modified Euler's method 5× Q4(c)

Method — predictor / corrector

Predictor: y₋₁⁽⁰⁾ = yₙ + h f(xₙ, yₙ)
Corrector (iterate): y₋₁⁽ᵏ⁺¹⁾ = yₙ + (h/2)[f(xₙ,yₙ) + f(x₋₁, y₋₁⁽ᵏ⁾)]
Repeat the corrector until two successive values agree — papers usually say "two iterations at each stage".

Worked — P26 9(d)

dy/dx = −y/(1+x), y(3) = 2, find y(3.2), h = 0.2.

f(3, 2) = −2/4 = −0.5

stepvalue
Predictor2 + 0.2(−0.5) = 1.900000

The corrector uses f at the new x with the latest y estimate, while f(xₙ,yₙ) stays fixed throughout. Recomputing the first term each time is the standard error.

10   Runge-Kutta, fourth order 6× — every paper Q3(d)/Q4(d)

Method

k₁ = h f(xₙ, yₙ) · k₂ = h f(xₙ+h/2, yₙ+k₁/2) · k₃ = h f(xₙ+h/2, yₙ+k₂/2) · k₄ = h f(xₙ+h, yₙ+k₃)
Δy = (k₁ + 2k₂ + 2k₃ + k₄)/6,   y₋₁ = yₙ + Δy

Worked — P26 10(d)

dy/dx = y − x², y(2) = 5, find y(2.1), h = 0.1.

11   Newton's law of cooling 5× Q3(b)/(c)/(d), Q4(d)

Method

dT/dt = −k(T − T₀) → T = T₀ + (T₁ − T₀)e⁻ᵏᵗ  (T₀ = room temperature, T₁ = initial temperature). Use the one intermediate reading to find k, then solve for the time asked.

Worked — MP 3(d) / P26 6(c) verbatim repeat

Coffee 92°C, room 24°C, cools to 80°C in 1 minute. When does it reach 65°C?

T = 24 + 68 e⁻ᵏᵗ. At t = 1: 80 = 24 + 68e⁻ᵏ → e⁻ᵏ = 56/68 = 14/17 → k = ln(17/14) = 0.194156

For T = 65: 41 = 68e⁻ᵏᵗ → t = ln(68/41)/0.194156

t = 2.606 minutes (about 2 min 36 s)

Trap

Subtract the room temperature before taking logs. The M24 variant uses 90 / 24 / 75 / 60 — same working, different numbers.

12   Orthogonal trajectories — Cartesian 6× Q3(b)/(d)

Method

  1. Differentiate the family and eliminate the parameter to get its DE.
  2. Replace dy/dx by −dx/dy.
  3. Solve the new DE.

Worked — P26 5(c): co-axial circles x² + y² + 2gx + c = 0, g the parameter

Differentiate: 2x + 2y y′ + 2g = 0 → g = −(x + y y′). Substituting back eliminates g:

x² + y² − 2x(x + y y′) + c = 0 → y² − x² + c = 2xy y′

Replace y′ → −1/y′: y² − x² + c = −2xy/y′, a homogeneous equation. Solving gives the orthogonal family x² + y² + 2λy − c = 0 — the conjugate system of co-axial circles.

Trap

You must eliminate the parameter before swapping y′. Swapping first and eliminating after is the commonest way to lose this question.

13   Orthogonal trajectories — polar, and self-orthogonal families 3× Q4(c)

Method — polar

Eliminate the parameter to get F(r, θ, dr/dθ) = 0, then replace dr/dθ by −r²(dθ/dr) — equivalently replace r dθ/dr by −(1/r)(dr/dθ).

Worked A — MAM24 3(b) / P26 6(b): show r = b sinθ is orthogonal to r = a cosθ

For r = a cosθ: dr/dθ = −a sinθ, and eliminating a gives (1/r)(dr/dθ) = −tanθ.

Swap: (1/r)(dr/dθ) → cotθ, i.e. dr/r = cotθ dθ → ln r = ln sinθ + ln b → r = b sinθ ✓

Worked B — M23 4(d) / MAE23 4(c): show x²/(a²+λ) + y²/(b²+λ) = 1 is self-orthogonal

Differentiating and eliminating λ gives a DE in which λ satisfies a quadratic. The key algebraic fact: the resulting differential equation contains y′ only through the combination (x + y y′)(y − x y′)-type symmetric terms, so substituting y′ → −1/y′ reproduces the same equation.

The family is therefore its own orthogonal trajectory — self-orthogonal. (These are confocal conics: every ellipse of the family cuts every hyperbola of it at right angles.)

Trap

Do not try to solve for λ explicitly. Show that the DE is invariant under y′ → −1/y′ — that is the whole proof.

14   LR and RC circuits 3× Q3(d)/Q4(d)

Method

LR: L(di/dt) + Ri = E(t)  ·  RC: R(dq/dt) + q/C = E(t), with i = dq/dt
LC, no e.m.f. (the 2-marker): L(d²q/dt²) + q/C = 0
All are linear first-order — integrating factor eⁿᵗ/ᴱ or eᵗ/ᴴᶜ.

Worked — MAE23 3(d)

e = 200e⁻⁵ᵗ applied to R = 20Ω, C = 0.01 F, no initial charge.

20(dq/dt) + 100q = 200e⁻⁵ᵗ → dq/dt + 5q = 10e⁻⁵ᵗ

Integrating factor e⁵ᵗ: d(qe⁵ᵗ)/dt = 10 → qe⁵ᵗ = 10t + A, and q(0)=0 gives A = 0.

q(t) = 10t e⁻⁵ᵗ    i(t) = dq/dt = 10(1 − 5t)e⁻⁵ᵗ

Trap

Here the forcing term e⁻⁵ᵗ matches the complementary function, so the particular integral picks up a factor of t — that is why the answer is 10te⁻⁵ᵗ and not a plain exponential. Recognising this resonance case is the whole question. Note 1/C = 100, not 0.01.

UNIT III  —  Q5 and Q6

Everything in this unit sits on CF + P.I. Learn that first; Cauchy, Legendre, IVP/BVP and variation of parameters are all built on top of it. Cauchy and Legendre in particular reduce to a constant-coefficient problem, so you get them almost free.

16   Cauchy's linear differential equation 4× Q5(c)/(d)

Method — the 4 steps (this is also the 2-mark answer)

  1. Put x = eᶻ, i.e. z = log x. Write D = d/dz.
  2. Then x y′ = Dy,  x²y″ = D(D−1)y,   x³y′″ = D(D−1)(D−2)y.
  3. The equation becomes constant-coefficient in z. Solve for CF and P.I. as usual.
  4. Substitute back z = log x.

Worked — MAE23 6(d): x²y″ − 4xy′ + 6y = cos(2 log x)

With x = eᶻ: D(D−1)y − 4Dy + 6y = cos 2z → (D² − 5D + 6)y = cos 2z

CF: m²−5m+6 = (m−2)(m−3) → C₁e²ᶻ + C₂e³ᶻ = C₁x² + C₂x³

P.I.: replace D² → −4: 1/(−4−5D+6)cos2z = 1/(2−5D)cos2z

Multiply above and below by (2+5D): (2+5D)cos2z/(4−25D²) = (2cos2z − 10sin2z)/(4+100)

y = C₁x² + C₂x³ + [cos(2 log x) − 5 sin(2 log x)]/52

Trap

x²y″ = D(D−1)y, not D²y — the −D is the single most common slip in this unit. Also cos(2 log x) becomes cos 2z, so treat z as the variable throughout and only convert back at the very end.

17   Legendre's linear differential equation 4× Q6(c)/(d)

Method — identical to Cauchy, one extra factor

Put ax + b = eᶻ. Then
(ax+b)y′ = aDy  ·  (ax+b)²y″ = a²D(D−1)y  ·  (ax+b)³y′″ = a³D(D−1)(D−2)y
Everything else is the same. Cauchy is just Legendre with a=1, b=0.

Worked — MAE23 5(b): (2x+3)²y″ + 2(2x+3)y′ − 12y = 0

Here a = 2. Put 2x+3 = eᶻ:

4D(D−1)y + 2·2Dy − 12y = 0 → 4D² − 4D + 4D − 12 = 0 → 4D² = 12 → m = ±√3

y = C₁e√³ᶻ + C₂e⁻√³ᶻ

y = C₁(2x+3)√³ + C₂(2x+3)⁻√³  (verified by substitution)

Trap

Forgetting the a² on the second-derivative term. With a = 2 that factor is 4 — drop it and the auxiliary equation, and every root, is wrong.

18   Method of variation of parameters 5× — every paper Q5(c)/(d)

Method

For y″ + Py′ + Qy = R with CF yᶜ = C₁y₁ + C₂y₂:
  1. Wronskian W = y₁y₂′ − y₂y₁′
  2. yᵧ = −y₁∫(y₂R/W)dx + y₂∫(y₁R/W)dx
The equation must be in standard form — coefficient of y″ equal to 1 — before you read off R.

Worked — MAM24 6(c): y″ − 6y′ + 9y = e³ₓ/x²

CF: (m−3)² = 0 → y₁ = e³ₓ, y₂ = xe³ₓ

Wronskian: W = e³ₓ(e³ₓ + 3xe³ₓ) − xe³ₓ·3e³ₓ = e⁶ₓ

y₂R/W = xe³ₓ·(e³ₓ/x²)/e⁶ₓ = 1/x → ∫ = log x

y₁R/W = e³ₓ·(e³ₓ/x²)/e⁶ₓ = 1/x² → ∫ = −1/x

yᵧ = −e³ₓlog x + xe³ₓ(−1/x) = −e³ₓ(log x + 1)

y = (C₁ + C₂x − log x)e³ₓ  (the −1 is absorbed into C₁)

Trap

Papers choose an R that is deliberately awkward for the P.I. rules — sec³x, tan x, e³ₓ/x², cos(e⁻ₓ). That awkwardness is the signal to use variation of parameters. Watch the minus sign on the first integral.

19   Initial and boundary value problems 6× Q5(b)/Q6(b)/(d)

Method

Find the general solution first (CF + P.I.), then apply the conditions. IVP = both conditions at the same x (e.g. y(0) and y′(0)). BVP = conditions at two different x values.

Worked A — P26 5(b), BVP: y″ + y = 0, y(0)=2, y(π/2) = −2

y = A cos x + B sin x. y(0) = A = 2; y(π/2) = B = −2.

y = 2cos x − 2sin x = 2√2 cos(x + π/4)

Worked B — M23 6(d), IVP: (D² − 2D)y = eₓ sin x, y(0)=8, y′(0)=1

CF: m(m−2)=0 → C₁ + C₂e²ₓ

P.I.: shift rule, eₓ·[1/((D+1)²−2(D+1))]sin x = eₓ[1/(D²−1)]sin x; replace D²→−1: = −eₓsin x/2

General: y = C₁ + C₂e²ₓ − eₓsin x/2. Applying both conditions:

y = 29/4 + (3/4)e²ₓ − eₓsin x/2

Trap

Apply conditions to the complete solution including the P.I. — fitting constants to the CF alone is a guaranteed zero. Differentiate the full expression before using y′(0).

UNIT IV  —  Q7 and Q8

Build the difference table first, every time. Interpolation, missing terms, numerical differentiation and grouped-frequency questions all start from the same table — only the formula you feed it into changes. Draw it once, carefully, and half the unit is done.

20   Newton-Gregory forward and backward interpolation 2× Q7(c)

Method

Forward (use when x is near the start), p = (x − x₀)/h:
y = y₀ + pΔy₀ + p(p−1)/2! ·Δ²y₀ + p(p−1)(p−2)/3! ·Δ³y₀ + …
Backward (use when x is near the end), p = (x − xₙ)/h:
y = yₙ + p∇yₙ + p(p+1)/2! ·∇²yₙ + p(p+1)(p+2)/3! ·∇³yₙ + …
Note the sign pattern: forward has (p−1)(p−2), backward has (p+1)(p+2).

21   Lagrange's interpolation (and inverse) 3× Q7(b)/(c), Q8(c)

Method

y = Σᵢ yᵢ · Πⱼ≠ᵢ (x − xⱼ)/(xᵢ − xⱼ)
Inverse interpolation — to find x given y — is the identical formula with the roles of x and y swapped: x = Σᵢ xᵢ · Πⱼ≠ᵢ (y − yⱼ)/(yᵢ − yⱼ)
Works for unequally spaced data — that is when to reach for it.

Worked — MAM24 7(b): find f(1) from (−1, 9), (0, 5), (2, 3)

y = 9·(x−0)(x−2)/((−1)(−3)) + 5·(x+1)(x−2)/((1)(−2)) + 3·(x+1)(x−0)/((3)(2))

Simplifying: P(x) = x² − 3x + 5

f(1) = 1 − 3 + 5 = 3

Trap

The denominators use the xᵢ values, never x. For the 2-mark "write Lagrange's inverse interpolation formula" for two points, the answer is simply x = x₀(y−y₁)/(y₀−y₁) + x₁(y−y₀)/(y₁−y₀).

22   Newton's divided difference 5× — every paper Q7(d)/Q8(c)

Method

f[x₀,x₁] = (f₁−f₀)/(x₁−x₀), and higher orders recursively.
P(x) = f₀ + (x−x₀)f[x₀,x₁] + (x−x₀)(x−x₁)f[x₀,x₁,x₂] + …
Also works for unequal spacing, and unlike Lagrange it is easy to extend when a point is added.

23   Finding missing terms 3× Q8(b)

Method

With n known values, a polynomial of degree n−1 fits, so all differences of order n vanish. Set Δⁿyᵢ = 0 for as many i as you have unknowns, and solve.
3 known values → quadratic fits → set every third difference to zero.

Worked — MAM24 8(b) / P26 8(b) identical data twice

x4550556065
y3.0a2.0b−2.4

Three known values → quadratic → both third differences vanish:

Δ³y₀ = 3a + b − 9 = 0  and  Δ³y₁ = −a − 3b + 3.6 = 0

Solving: y(50) = a = 2.925    y(60) = b = 0.225

Check — second differences become −0.85, −0.85, −0.85, constant as required. Always show this check; it is worth a mark.

Trap

Two unknowns need two equations. Setting a single fourth difference to zero gives only the relation a + b = 3.15 and cannot be solved — students get stuck here. Use the third differences, both of them.

24   Grouped-frequency estimation 3× Q7(c)/Q8(c)/(d)

Method — the part nobody spots

The data are given per class, but interpolation needs a cumulative ("less than") column.
  1. Convert the class frequencies to cumulative totals against the class upper bounds.
  2. Interpolate the cumulative value at the point asked.
  3. Subtract to recover the count in the sub-interval.

Worked — P26 7(c): students scoring between 70 and 75

Marks30–4040–5050–6060–7070–80
Students3142513531

Cumulative — students scoring less than:

Forward differences: Δ = 42, 51, 35, 31; Δ² = 9, −16, −4; Δ³ = −25, 12; Δ⁴ = 37.

p = (75 − 40)/10 = 3.5, giving y(75) = 172.80.

Students between 70 and 75 = 172.80 − 159 = 13.80 ≈ 14

Trap

Interpolating the raw class frequencies instead of the cumulative column. That is the whole difficulty of this question — and it is worth 7 marks three papers running.

25   Numerical differentiation 4× Q7(d)/Q8(c)

Method

Differentiate the interpolation polynomial. Forward, with p = (x−x₀)/h:
dy/dx = (1/h)[Δy₀ + (2p−1)/2 ·Δ²y₀ + (3p²−6p+2)/6 ·Δ³y₀ + …]
Backward, with p = (x−xₙ)/h:
dy/dx = (1/h)[∇yₙ + (2p+1)/2 ·∇²yₙ + (3p²+6p+2)/6 ·∇³yₙ + …]
At x = x₀ exactly, p = 0 and the forward formula collapses to (1/h)[Δy₀ − Δ²y₀/2 + Δ³y₀/3 − …].

Worked — P26 7(d): rate of cooling at t = 8 s

t13579

h = 2. Since t = 8 is near the end, use backward from tₙ = 9, p = (8−9)/2 = −0.5.

Backward differences at the end: ∇θ = −6.2, ∇²θ = 0.3, ∇³θ = −0.7, ∇⁴θ = 1.6.

dθ/dt at t = 8 is −3.1187 °C per second

Do not forget the 1/h outside — with h = 2 that halves your answer. The result is negative because the body is cooling; a positive answer means a sign slip.

26–28   Numerical integration — all three rules 5× Q7(d)/Q8(b)/(d)

The three formulas

Trapezoidal (any n): (h/2)[(y₀+yₙ) + 2(all interior)]
Simpson's 1/3 (n even): (h/3)[(y₀+yₙ) + 4(odd-indexed) + 2(even-indexed interior)]
Simpson's 3/8 (n a multiple of 3): (3h/8)[(y₀+yₙ) + 3(all not divisible by 3) + 2(indices divisible by 3)]
"Seven equidistant ordinates" means n = 6 intervals.

Worked — the recurring integral ∫₀¹ dx/(1+x²) 3 papers, 3 different rules

UNIT V  —  Q9 and Q10

Eigenvalues are the spine of this unit. Diagonalization, Rayleigh's power method and system-of-ODEs-by-matrix are all "find the eigenvalues, then do one more step". Learn the eigen-step once and three 7-markers open at the same time.

29   Rank, echelon form and consistency 2× Q9(b)/Q10(c)

Method

Row-reduce the augmented matrix [A|B]. With n unknowns:
  • rank(A) ≠ rank(A|B) → inconsistent, no solution
  • rank(A) = rank(A|B) = n → unique solution
  • rank(A) = rank(A|B) = r < n → infinitely many, with n − r free parameters

Worked — conditions on a, b, c for solvability

x + 2y − z = a;  2x + y + z = b;   x − y + 2z = c

The coefficient determinant is 0 and rank(A) = 2, so a condition is needed. Adding rows 1 and 3: 2x + y + z = a + c. But row 2 says 2x + y + z = b.

Condition for consistency: b = a + c

When it holds, rank = 2 < 3, so there is a one-parameter family. Taking a=1, b=3, c=2 and z = t free:

x = 5/3 − t,   y = t − 1/3,   z = t

Trap — and a note on the 2023 paper

When rank < n you must present a family with a named parameter, not a single triple.
The exact constants in M23 10(c) are not legible in the scan — the method above is what matters, and the structure (det = 0, one linear condition on a, b, c, one free parameter) is standard.

30   Gauss elimination 2× Q9(d)/Q10(c)

Method

Form [A|B], reduce to upper triangular by row operations, then back-substitute. In word problems the real work is writing the system — one equation per constraint, one unknown per quantity asked for.

Worked — M24 10(c): the dietician problem

31   Gauss-Seidel iteration 4× Q9(b)/Q10(b)/(c)

Method

  1. Reorder the equations for diagonal dominance — each diagonal entry larger in magnitude than the sum of the others in its row. Without this the iteration may not converge.
  2. Solve each equation for its diagonal variable.
  3. Sweep in order, using each new value immediately within the same iteration. (That is the difference from Jacobi.)

Worked — MP 10(c) / P26 2(b) identical system twice

Given as: x + 8y + 2z = −4; 10x + 2y + z = 59; 2x − y + 20z = 74

Reorder to 10x + 2y + z = 59; x + 8y + 2z = −4; 2x − y + 20z = 74, then

x = (59 − 2y − z)/10,   y = (−4 − x − 2z)/8,   z = (74 − 2x + y)/20

32   Eigenvalues and eigenvectors foundation Q9(c)/(d)

Method

  1. Solve |A − λI| = 0 for the eigenvalues.
  2. For each λ, solve (A − λI)X = 0 for the eigenvector.
Checks worth doing: sum of eigenvalues = trace; product = determinant. Both are free marks and catch algebra slips.

Worked — A = [[1, −1], [2, 4]]

|A − λI| = (1−λ)(4−λ) + 2 = λ² − 5λ + 6 = (λ−2)(λ−3)

λ = 2, 3. Check: trace = 5 = 2+3 ✓, det = 6 = 2×3 ✓

λ=2: (A−2I)X=0 → −x − y = 0 → X₁ = [−1, 1]ᵀ
λ=3: −2x − y = 0 → X₂ = [−1, 2]ᵀ

Trap

Eigenvectors are determined only up to a scale factor — any non-zero multiple is correct. Never "solve" to a unique vector and never report the zero vector.

33   Diagonalization and Aⁿ 3×/3 Q9(c)/(d)

Method

Build the modal matrix P from the eigenvectors as columns, and the spectral matrix D = diag(λᵢ) in the same order. Then P⁻¹AP = D, so A = PDP⁻¹ and Aⁿ = P Dⁿ P⁻¹ — and Dⁿ is just the diagonal entries raised to the power.

Worked — MP 9(c): diagonalize A = [[1,−1],[2,4]], hence find A⁸

From above, P = [[−1, −1], [1, 2]] and D = diag(2, 3).

P⁻¹ = [[−2, −1], [1, 1]]  (det P = −1)

A⁸ = P·diag(2⁸, 3⁸)·P⁻¹ = P·diag(256, 6561)·P⁻¹

A⁸ = [[−6049, −6305], [12610, 12866]]  (verified against direct multiplication)

Trap

The columns of P and the diagonal of D must be in the same order. Swap one and everything after is wrong. For the 2-marker: the modal matrix is P, the spectral matrix is D. And "is every square matrix diagonalizable?" — no: it needs n linearly independent eigenvectors, which repeated eigenvalues can fail to provide.

34   Rayleigh's power method 3×/3 Q9(c)/(d), Q10(b)

Method

Repeat: Y = A X, then factor out the largest-magnitude component m so that X₋₁ = Y/m. The m values converge to the dominant eigenvalue and X to its eigenvector.

The model paper asks for two decimal places, which needs about ten iterations. If the sequence is still jumping, keep going and say so.

35   System of ODEs by matrix method 3×/3 — always Q10(d) Q10(d)

Method

Write the system as X′ = AX.
  1. Find the eigenvalues λᵢ and eigenvectors Vᵢ of A.
  2. General solution X = c₁V₁eᴱ¹ᵗ + c₂V₂eᴱ²ᵗ.
  3. Apply the initial conditions to fix c₁, c₂.

Worked — M23 10(d): rabbits and wolves

dr/dt = 4r − 2w, dw/dt = r + w, r(0) = 240, w(0) = 300.

A = [[4, −2], [1, 1]], |A−λI| = λ² − 5λ + 6 = (λ−2)(λ−3)

λ = 2 → V = [1, 1]ᵀ;   λ = 3 → V = [2, 1]ᵀ

r = c₁e²ᵗ + 2c₂e³ᵗ,   w = c₁e²ᵗ + c₂e³ᵗ

At t=0: c₁ + 2c₂ = 240, c₁ + c₂ = 300 → c₂ = −60, c₁ = 360

r(t) = 360e²ᵗ − 120e³ᵗ    w(t) = 360e²ᵗ − 60e³ᵗ

Check: r(0) = 360−120 = 240 ✓, w(0) = 360−60 = 300 ✓

Trap

The eigenvector components must stay attached to the right variable — if V = [2,1]ᵀ belongs to λ=3, then r gets the 2 and w gets the 1. Always substitute t = 0 back at the end; it catches a swapped pair instantly. This has been the final question of the exam in all three papers.
Two habits worth more than any single formula.
1. Check your answer when the question hands you a way to. Initial conditions, trace and determinant, constant differences in a table, the exact value of an integral — each is a free verification and often a mark in itself.
2. Show the table. Every iterative method here is method-marked. A Gauss-Seidel, RK4 or difference table with a slip in the last row still scores most of the marks; a bare final answer scores few.
