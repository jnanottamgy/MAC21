MAC21 — 4-Mark Bank, Every Single Step

Same 45 questions, but nothing skipped. Every derivative is computed in front of you, every integral is named, every line of algebra is shown. No step assumes you already know calculus.

NO CALCULUS = pure arithmetic, you can do these today  ·  NEEDS CALCULUS = uses a derivative or integral, all of which are in the toolkit below.
Good news first: Units IV and V are almost entirely arithmetic. Difference tables, Gauss-Seidel, Lagrange, trapezoidal, determinants — that is 15 of the 45 questions with no calculus at all. If maths is fighting you, start there.

UNIT I  —  Q1(b) or Q2(b)

1   Show f(x,y) = xy(1−x−y) is maximum at (1/3, 1/3)  3× NEEDS CALCULUS

Step 1 Multiply it out first — much easier to differentiate.
f = xy(1 − x − y) = xy − x²y − xy²

Step 2 Find fₓ. Treat y as a plain number.
• xy → y is a number multiplying x, so this differentiates to y
• −x²y → −y·(2x) = −2xy
• −xy² → y² is a number, so this gives −y²
fₓ = y − 2xy − y²

Step 3 Find fᵧ. Treat x as a plain number.
fᵧ = x − x² − 2xy

Step 4 Set both to zero and check the given point works.
Put x = 1/3, y = 1/3 into fₓ:
1/3 − 2(1/3)(1/3) − (1/3)² = 1/3 − 2/9 − 1/9 = 3/9 − 2/9 − 1/9 = 0 ✓
By symmetry fᵧ = 0 too. So (1/3,1/3) is a stationary point.

Step 5 Differentiate a second time to get r, s, t.
• r = fₓₓ = differentiate fₓ = y − 2xy − y² w.r.t. x again → only −2xy has an x → r = −2y
• s = fₓᵧ = differentiate fₓ w.r.t. y → s = 1 − 2x − 2y
• t = fᵧᵧ = differentiate fᵧ = x − x² − 2xy w.r.t. y → t = −2x

Step 6 Put (1/3, 1/3) in — now it is only arithmetic.
r = −2/3  ·  s = 1 − 2/3 − 2/3 = −1/3  ·  t = −2/3
rt − s² = (−2/3)(−2/3) − (−1/3)² = 4/9 − 1/9 = 3/9 = 1/3

Step 7 Apply the test.
rt − s² = 1/3 > 0 and r = −2/3 < 0 → MAXIMUM
Value: f = (1/3)(1/3)(1 − 1/3 − 1/3) = (1/9)(1/3) = 1/27

2   Examine x³ + y³ − 3axy for extreme values  1× NEEDS CALCULUS

Step 1 fₓ: treat y as a number. x³ → 3x²; y³ → 0 (no x in it); −3axy → −3ay.
fₓ = 3x² − 3ay    and similarly    fᵧ = 3y² − 3ax

Step 2 Set both zero: x² = ay  and  y² = ax.
From the first, y = x²/a. Put that into the second: (x²/a)² = ax → x⁴/a² = ax → x⁴ = a³x → x(x³ − a³) = 0
So x = 0 or x = a. Stationary points: (0,0) and (a,a).

Step 3 Second derivatives: r = fₓₓ = 6x,  s = fₓᵧ = −3a,  t = fᵧᵧ = 6y
rt − s² = 36xy − 9a²

Step 4 Test each point.
At (0,0): rt − s² = 0 − 9a² = −9a² < 0 → saddle point
At (a,a): rt − s² = 36a² − 9a² = 27a² > 0, and r = 6a
  → if a > 0, r > 0 so minimum; if a < 0, maximum
Value there: a³ + a³ − 3a·a·a = −a³

3   Expand aₓ in powers of x, first three terms  1× NEEDS CALCULUS

Formula Maclaurin: f(x) = f(0) + x f′(0) + (x²/2!) f″(0) + …  (2! = 2)

Step 1 f = aₓ → at x=0: a⁰ = 1

Step 2 f′ = aₓ·log a → at 0: 1·log a = log a

Step 3 f″: differentiate aₓ log a. log a is a constant, so it just rides along: f″ = aₓ(log a)² → at 0: (log a)²

Step 4 Substitute: aₓ = 1 + x log a + x²(log a)²/2 + …

4   Expand sin⁻¹x in powers of x  1× NEEDS CALCULUS

Trick Differentiating sin⁻¹x repeatedly is horrible. Instead: differentiate once, expand the simple thing you get, then integrate back.

Step 1 d/dx(sin⁻¹x) = 1/√(1−x²) = (1−x²)⁻½

Step 2 Binomial expansion of (1−u)⁻½ is 1 + u/2 + 3u²/8 + …. Put u = x²:
(1−x²)⁻½ = 1 + x²/2 + 3x⁴/8 + …

Step 3 Integrate term by term (raise the power by 1, divide by the new power):
∫1 dx = x  ·  ∫(x²/2)dx = x³/6  ·  ∫(3x⁴/8)dx = 3x⁵/40

Answer sin⁻¹x = x + x³/6 + 3x⁵/40 + …
The constant is 0 because sin⁻¹(0) = 0. All even powers are missing — say so, it is worth a mark.

5   Expand tan⁻¹x in powers of (x−1) to 4th degree  1× NEEDS CALCULUS

Formula Taylor about a=1: f(x) = f(1) + (x−1)f′(1) + (x−1)²f″(1)/2! + (x−1)³f′″(1)/3! + (x−1)⁴fⁱᵛ(1)/4!
2! = 2, 3! = 6, 4! = 24

Step 1 f = tan⁻¹x → f(1) = tan⁻¹(1) = π/4

Step 2 f′ = 1/(1+x²) → f′(1) = 1/2

Step 3 f″ = −2x/(1+x²)² → f″(1) = −2/4 = −1/2

Step 4 f′″ = (6x²−2)/(1+x²)³ → f′″(1) = 4/8 = 1/2

Step 5 fⁱᵛ(1) = 0  (it works out to zero at x=1)

Step 6 Substitute, dividing by the factorials:
π/4 + (x−1)(1/2) + (x−1)²(−1/2)/2 + (x−1)³(1/2)/6 + 0

Answer tan⁻¹x = π/4 + (x−1)/2 − (x−1)²/4 + (x−1)³/12 + 0·(x−1)⁴

6   Newton-Raphson system, ONE iteration, from (0.8, 0.4)  1× easy calculus only

Setup x²+y² = x and x²−y² = y. Move everything to one side:
f = x² + y² − x    g = x² − y² − y

Step 1 Four partial derivatives (all just power rule):
fₓ = 2x − 1  ·  fᵧ = 2y  ·  gₓ = 2x  ·  gᵧ = −2y − 1

Step 2 Evaluate everything at (0.8, 0.4) — pure arithmetic from here.
f = 0.64 + 0.16 − 0.8 = 0.0000   (zero — that is fine, not an error)
g = 0.64 − 0.16 − 0.4 = 0.0800
fₓ = 0.6, fᵧ = 0.8, gₓ = 1.6, gᵧ = −1.8

Step 3 Solve the two linear equations for the corrections h, k:
0.6h + 0.8k = −0.0000
1.6h − 1.8k = −0.0800
From the first, h = −(0.8/0.6)k = −1.3333k. Substitute:
1.6(−1.3333k) − 1.8k = −0.08 → −2.1333k − 1.8k = −0.08 → −3.9333k = −0.08
k = 0.020339,  h = −1.3333(0.020339) = −0.027119

Step 4 Update: x₁ = 0.8 − 0.027119, y₁ = 0.4 + 0.020339
x₁ = 0.772881,   y₁ = 0.420339

7   Newton-Raphson system from (3.5, −1.8), one iteration  1×

Setup f = x² + y − 11,  g = y² + x − 7

Step 1 fₓ = 2x, fᵧ = 1, gₓ = 1, gᵧ = 2y

Step 2 At (3.5, −1.8):
f = 12.25 − 1.8 − 11 = −0.5500  ·  g = 3.24 + 3.5 − 7 = −0.2600
fₓ = 7, fᵧ = 1, gₓ = 1, gᵧ = −3.6

Step 3 7h + k = 0.55  and  h − 3.6k = 0.26
From the first, k = 0.55 − 7h. Substitute: h − 3.6(0.55 − 7h) = 0.26
h − 1.98 + 25.2h = 0.26 → 26.2h = 2.24 → h = 0.085496
k = 0.55 − 7(0.085496) = −0.048473

Answer x₁ = 3.585496,   y₁ = −1.848473

8   Negative root of x eₓ − sin x = 0 to three decimals  2× NEEDS CALCULUS

Step 1 — find where the root is. Put in numbers until the sign flips:
f(−2.9) = (−2.9)(0.0550) − sin(−2.9) = −0.1596 + 0.2392 = +0.0796
f(−3.0) = (−3.0)(0.0498) − sin(−3.0) = −0.1494 + 0.1411 = −0.0083
Sign changes → root lies between −3.0 and −2.9. Start at x₀ = −3.
Do not start near 0 — x=0 is also a root and the method will slide into it.

Step 2 — the derivative. x eₓ is a product, so use the product rule:
d/dx(x eₓ) = (1)(eₓ) + (x)(eₓ) = eₓ(1+x); and d/dx(−sin x) = −cos x
f′(x) = eₓ(1+x) − cos x

Step 3 — iterate x₋ = x − f(x)/f′(x).
At x = −3: f = −0.008240; f′ = 0.0498(−2) − (−0.98999) = −0.0996 + 0.98999 = 0.89039
x₁ = −3 − (−0.008240/0.89039) = −3 + 0.009255 = −2.990745
Repeat once: x₂ = −2.990735 — the first three decimals have stopped moving.

Answer root = −2.991

14   Taylor's series method: dy/dt = eᵗ − 2y, y(0)=1, at t=0.1  2× NEEDS CALCULUS

The formula y(t) = y₀ + t·y′₀ + (t²/2!)y″₀ + (t³/3!)y′″₀, all derivatives at the start point.

Step 1 The DE is y′:  y′ = eᵗ − 2y

Step 2 Differentiate that. Key point: y is a function of t, so d/dt(y) = y′, not zero.
y″ = d/dt(eᵗ) − 2·d/dt(y) = eᵗ − 2y′

Step 3 Again: y′″ = eᵗ − 2y″

Step 4 Now put in t = 0, y = 1 and work downwards — each line uses the one above.
y′ = e⁰ − 2(1) = 1 − 2 = −1
y″ = e⁰ − 2(−1) = 1 + 2 = 3
y′″ = e⁰ − 2(3) = 1 − 6 = −5

Step 5 Substitute with t = 0.1 (2! = 2, 3! = 6):
y = 1 + (0.1)(−1) + (0.01/2)(3) + (0.001/6)(−5)
= 1 − 0.1 + 0.015 − 0.000833

Answer y(0.1) = 0.914167

15   Newton's law of cooling: 300°F, room 80°F, 250°F after 10 min — find T(20)  2× NO CALCULUS NEEDED

Use the ready-made formula — you do not have to solve the differential equation:
T = T₀ + (T₁ − T₀)e⁻ᵏᵗ,   T₀ = room temp, T₁ = starting temp.

Step 1 T₀ = 80, T₁ = 300, so T₁ − T₀ = 220:
T = 80 + 220 e⁻ᵏᵗ

Step 2 Use the 10-minute reading to pin down e⁻¹⁰ᵏ:
250 = 80 + 220 e⁻¹⁰ᵏ → 170 = 220 e⁻¹⁰ᵏ → e⁻¹⁰ᵏ = 170/220 = 17/22

Step 3 — the shortcut. You do not need k. Notice e⁻²⁰ᵏ = (e⁻¹⁰ᵏ)² — just square it:
e⁻²⁰ᵏ = (17/22)² = 289/484 = 0.597107

Step 4 T(20) = 80 + 220(0.597107) = 80 + 131.364

Answer T(20) = 211.36 °F

16   Orthogonal trajectory of cardioids r = a(1−cosθ)  1× NEEDS CALCULUS

Given the family's DE is already handed to you: dr/dθ = r cot(θ/2).

Step 1 — the swap. For polar, replace dr/dθ by −r²(dθ/dr):
−r²(dθ/dr) = r cot(θ/2)

Step 2 — tidy up. Divide both sides by r: −r(dθ/dr) = cot(θ/2).
Now separate — get all the r on one side, all the θ on the other:
−r dθ = cot(θ/2) dr → dr/r = −tan(θ/2) dθ

Step 3 — integrate both sides.
Left: ∫dr/r = log r
Right: ∫−tan(θ/2)dθ. Using ∫tan u du = −log(cos u) with u = θ/2 (so dθ = 2du): this gives +2 log(cos(θ/2))
So log r = 2 log cos(θ/2) + log c

Step 4 — undo the logs. 2 log A = log A² and log A + log B = log AB:
log r = log(c cos²(θ/2)) → r = c cos²(θ/2)

Step 5 Use cos²(θ/2) = (1 + cosθ)/2:

Answer r = C(1 + cosθ)  — the same cardioid, reflected.

17   If rⁿ = k cos(nθ), find the DE of that family  1× NEEDS CALCULUS

Aim Get rid of the parameter k. Taking logs first makes this easy.

Step 1 log(rⁿ) = log k + log(cos nθ) → n log r = log k + log cos nθ

Step 2 Differentiate w.r.t. θ. log k is a constant → 0.
Left: n·d/dθ(log r) = n·(1/r)(dr/dθ)  (chain rule — r depends on θ)
Right: d/dθ(log cos nθ) = (1/cos nθ)·(−n sin nθ) = −n tan nθ

Step 3 n(1/r)(dr/dθ) = −n tan nθ. Cancel n:

Answer (1/r)(dr/dθ) = −tan(nθ),  i.e. dr/dθ + r tan(nθ) = 0

18   Orthogonal trajectory of r = b sinθ  2× NEEDS CALCULUS

Step 1 — eliminate b. dr/dθ = b cosθ. Since b = r/sinθ:
dr/dθ = (r/sinθ)cosθ = r cotθ → (1/r)(dr/dθ) = cotθ

Step 2 — swap. Replacing dr/dθ → −r²dθ/dr turns cotθ into −tanθ:
(1/r)(dr/dθ) = −tanθ

Step 3 — separate and integrate.
dr/r = −tanθ dθ → log r = −(−log cosθ) + log c = log cosθ + log c

Answer r = c cosθ

UNIT III  —  Q5(b) or Q6(b)

21   Prove (1/(D+a))X = e⁻ᵃₓ∫X eᵃₓ dx  4× — the safest 4 marks in the paper light calculus

What the notation means D means "differentiate", so Dy = dy/dx. 1/(D+a) means "undo (D+a)". Nothing to memorise numerically — this proof never changes.

Step 1 Call the answer y:  y = (1/(D+a))X

Step 2 Multiply both sides by (D+a) to clear the fraction:
(D+a)y = X,  which written out is  dy/dx + ay = X

Step 3 This is a standard linear equation dy/dx + Py = Q with P = a.
Its integrating factor is e∫᱿ᵈᵄ = e∫ᵃᵈᵄ = eᵃₓ.

Step 4 Multiply the whole equation by eᵃₓ:
eᵃₓ(dy/dx) + a eᵃₓ y = X eᵃₓ

Step 5 — spot the product rule backwards. The left side is exactly what you get if you differentiate y·eᵃₓ:
d/dx(y eᵃₓ) = (dy/dx)eᵃₓ + y(a eᵃₓ)  ✓ same thing.
So the equation is simply d/dx(y eᵃₓ) = X eᵃₓ

Step 6 Integrate both sides w.r.t. x. On the left, integrating a derivative just undoes it:
y eᵃₓ = ∫X eᵃₓ dx

Step 7 Divide by eᵃₓ (dividing by eᵃₓ is multiplying by e⁻ᵃₓ):

Answer y = e⁻ᵃₓ ∫X eᵃₓ dx  ■  Seven lines. Learn them.

22   General solution if the A.E. is λ³(λ+4)²(λ²+2λ+5)² = 0  1× NO CALCULUS

Step 1 — read off the roots.
λ³ = 0 → λ = 0, three times
(λ+4)² = 0 → λ = −4, twice
(λ²+2λ+5)² = 0 → solve λ²+2λ+5=0 by the quadratic formula:
λ = [−2 ± √(4−20)]/2 = [−2 ± √(−16)]/2 = (−2 ± 4i)/2 = −1 ± 2i, each twice

Step 2 — apply the rules.
• root m repeated k times → (C₁ + C₂x + … + Cᵏxᵏ⁻¹)eᵐₓ
• complex α ± iβ → eᴺₓ(A cosβx + B sinβx); if repeated, the constants become linear in x

Step 3 — build each piece.
λ=0 three times → (C₁+C₂x+C₃x²)e⁰ₓ = C₁+C₂x+C₃x²  (since e⁰ = 1)
λ=−4 twice → (C₄+C₅x)e⁻⁴ₓ
−1±2i twice → e⁻ₓ[(C₆+C₇x)cos2x + (C₈+C₉x)sin2x]

Answer y = (C₁+C₂x+C₃x²) + (C₄+C₅x)e⁻⁴ₓ + e⁻ₓ[(C₆+C₇x)cos2x + (C₈+C₉x)sin2x]

23   Show yⁱᵛ − k⁴y = 0 gives C₁cos kx + C₂sin kx + C₃cosh kx + C₄sinh kx  1× NO CALCULUS

Step 1 Auxiliary equation: replace yⁱᵛ by m⁴, y by 1:
m⁴ − k⁴ = 0

Step 2 Factorise as a difference of two squares (twice):
m⁴ − k⁴ = (m²)² − (k²)² = (m² − k²)(m² + k²) = 0

Step 3 m² = k² → m = ±k (real).  m² = −k² → m = ±ik (complex, α=0, β=k).

Step 4 Write the C.F.:
y = Aeᵏₓ + Be⁻ᵏₓ + e⁰ₓ(C cos kx + D sin kx)

Step 5 — convert the exponentials. By definition cosh kx = (eᵏₓ+e⁻ᵏₓ)/2 and sinh kx = (eᵏₓ−e⁻ᵏₓ)/2.
So eᵏₓ = cosh kx + sinh kx and e⁻ᵏₓ = cosh kx − sinh kx. Then
Aeᵏₓ + Be⁻ᵏₓ = (A+B)cosh kx + (A−B)sinh kx. Rename A+B = C₃, A−B = C₄.

Answer y = C₁cos kx + C₂sin kx + C₃cosh kx + C₄sinh kx ■

24   Solve the BVP y″ + 4y′ + 4y = 0, y(1)=0, y′(0)=−1  1× light calculus

Step 1 A.E.: m² + 4m + 4 = (m+2)² = 0 → m = −2, repeated.
Repeated root → y = (A + Bx)e⁻²ₓ

Step 2 — differentiate, using the product rule. Let u = A+Bx, v = e⁻²ₓ.
u′ = B,  v′ = −2e⁻²ₓ
y′ = u′v + uv′ = Be⁻²ₓ + (A+Bx)(−2e⁻²ₓ) = e⁻²ₓ[B − 2A − 2Bx]

Step 3 Apply y′(0) = −1. At x=0, e⁰ = 1:
B − 2A = −1  …(i)

Step 4 Apply y(1) = 0:
(A + B)e⁻² = 0. Since e⁻² ≠ 0, we need A + B = 0, so B = −A  …(ii)

Step 5 Put (ii) into (i): −A − 2A = −1 → −3A = −1 → A = 1/3, B = −1/3

Answer y = (1 − x)e⁻²ₓ / 3

25   Solve the IVP y″ − y = 0, y(0)=3, y′(0)=3  1× almost no calculus

Step 1 A.E.: m² − 1 = 0 → m = +1 and m = −1 → y = Aeₓ + Be⁻ₓ

Step 2 y′ = Aeₓ − Be⁻ₓ  (e⁻ₓ differentiates to −e⁻ₓ)

Step 3 At x=0, both exponentials are 1:
y(0) = A + B = 3  …(i)    y′(0) = A − B = 3  …(ii)

Step 4 Add (i) and (ii): 2A = 6 → A = 3. Then B = 0.

Answer y = 3eₓ

26   Find the P.I. of y″ − y′ = x² + 2x + 4  1× NEEDS CALCULUS

Step 1 In operator form: (D² − D)y = x²+2x+4, so yᵧ = (1/(D²−D))(x²+2x+4)

Step 2 Factor out −D so what is left starts with 1:
D² − D = −D(1 − D), so yᵧ = −(1/D)·(1/(1−D))·(x²+2x+4)

Step 3 Expand 1/(1−D) as a series (this is the binomial expansion (1−D)⁻¹ = 1 + D + D² + D³ + …). Stop at D² — higher terms kill a quadratic.

Step 4 Apply it. Here D just means "differentiate".
(1)(x²+2x+4) = x²+2x+4
(D)(x²+2x+4) = 2x+2
(D²)(x²+2x+4) = 2
Add them: x² + 2x + 4 + 2x + 2 + 2 = x² + 4x + 8

Step 5 Now the −(1/D). 1/D means integrate, and the minus flips the sign:
∫(x²+4x+8)dx = x³/3 + 2x² + 8x

Answer yᵧ = −(x³/3 + 2x² + 8x)

27   Solve the Legendre equation (2x+3)²y″ + 2(2x+3)y′ − 12y = 0  1× NO CALCULUS after the swap

Step 1 — the substitution. Put 2x+3 = eᶻ. Here a = 2 (whatever multiplies x).
The standard replacements are:
(2x+3)y′ = 2Dy    (2x+3)²y″ = 2²D(D−1)y = 4D(D−1)y
The 4 is the thing everyone forgets.

Step 2 — substitute.
4D(D−1)y + 2(2Dy) − 12y = 0
4D²y − 4Dy + 4Dy − 12y = 0
The −4Dy and +4Dy cancel: 4D²y − 12y = 0

Step 3 Divide by 4: D²y = 3y. A.E.: m² = 3 → m = ±√3

Step 4 y = C₁e√³ᶻ + C₂e⁻√³ᶻ

Step 5 — substitute back. Since eᶻ = 2x+3, we get e√³ᶻ = (eᶻ)√³ = (2x+3)√³.

Answer y = C₁(2x+3)√³ + C₂(2x+3)⁻√³

41–42   Gauss-Seidel  3× NO CALCULUS

System A 2x+17y+4z=35; 3x+y+10z=24; 28x+4y−z=32, start (0,0,0).

Step 1 — REORDER first. Each row needs its diagonal entry to be the biggest in that row.
Row with the big x is 28x+4y−z=32 → put it first.
Row with the big y is 2x+17y+4z=35 → second.
Row with the big z is 3x+y+10z=24 → third.

Step 2 — make each variable the subject.
x = (32 − 4y + z)/28  ·  y = (35 − 2x − 4z)/17  ·  z = (24 − 3x − y)/10

Step 3 — iterate, always using the newest values.
Iteration 1 (start y=0, z=0):
x = (32 − 0 + 0)/28 = 1.142857
y = (35 − 2(1.142857) − 0)/17 = (35 − 2.285714)/17 = 1.924370  ← uses the new x
z = (24 − 3(1.142857) − 1.924370)/10 = (24 − 3.428571 − 1.924370)/10 = 1.864706
Iteration 2:
x = (32 − 4(1.924370) + 1.864706)/28 = 0.934544
y = (35 − 2(0.934544) − 4(1.864706))/17 = 1.510123
z = (24 − 3(0.934544) − 1.510123)/10 = 1.968625

Answer After 2 iterations: x = 0.934544, y = 1.510123, z = 1.968625  (heading for 1.001, 1.482, 1.952)

System B 5x+2y+z=12; x+4y+2z=15; x+2y+5z=20, start (1,0,0). Already dominant — no reorder.
x=(12−2y−z)/5, y=(15−x−2z)/4, z=(20−x−2y)/5
It1: x = 12/5 = 2.4; y = (15−2.4−0)/4 = 3.15; z = (20−2.4−6.3)/5 = 2.26
It2: x = (12−6.3−2.26)/5 = 0.688; y = (15−0.688−4.52)/4 = 2.448; z = (20−0.688−4.896)/5 = 2.8832
x = 0.688, y = 2.448, z = 2.8832  (exact answer is 1, 2, 3)

43   Rayleigh's power method, 2 iterations  1× NO CALCULUS

Given A = [[2,−2,1],[1,3,−1],[−1,2,2]], X₀ = [1,0,0]ᵀ.

The method Multiply A by the vector; pull out the largest-size number as λ; what remains is the next vector.

Iteration 1 AX₀ = each row of A dotted with [1,0,0] = just the first column:
[2, 1, −1]ᵀ. Largest size is 2, so factor it out:
= 2[1, 0.5, −0.5]ᵀ → λ₁ = 2, X₁ = [1, 0.5, −0.5]ᵀ

Iteration 2 AX₁:
Row 1: 2(1) + (−2)(0.5) + 1(−0.5) = 2 − 1 − 0.5 = 0.5
Row 2: 1(1) + 3(0.5) + (−1)(−0.5) = 1 + 1.5 + 0.5 = 3
Row 3: −1(1) + 2(0.5) + 2(−0.5) = −1 + 1 − 1 = −1
= [0.5, 3, −1]ᵀ = 3[0.1667, 1, −0.3333]ᵀ

Answer λ = 3,   X = [0.167, 1, −0.333]ᵀ

Note This particular matrix has complex eigenvalues, so the method never really settles. The question asks for two iterations — do them and stop. If the numbers look unstable, that is the matrix, not you.

44   Find x so the matrix has rank 2  1× NO CALCULUS

Idea A 3×3 matrix has rank 3 unless its determinant is zero. So set |A| = 0.

Given A = [[4−x, 2√5, 0], [2√5, 4−x, √5], [0, √5, 4−x]]. Write u = 4−x.

Step 1 Expand along the top row:
|A| = u(u·u − √5·√5) − 2√5(2√5·u − √5·0) + 0
= u(u² − 5) − 2√5(2√5 u) = u³ − 5u − 20u = u³ − 25u = u(u² − 25)

Step 2 Set to zero: u = 0 or u = ±5, i.e. 4−x = 0, 5, −5

Answer x = 4,  x = −1,  x = 9  (at each of these a 2×2 minor is still non-zero, so the rank is exactly 2)

45   Prove: if λ is an eigenvalue of A then 1/λ is one of A⁻¹  1× NO CALCULUS

Step 1 By definition, AX = λX for some non-zero X.

Step 2 Multiply both sides on the left by A⁻¹:
A⁻¹(AX) = A⁻¹(λX)

Step 3 On the left, A⁻¹A = I and IX = X. On the right, λ is just a number so it slides out front:
X = λ(A⁻¹X)

Step 4 Divide by λ. (Allowed: A is invertible, so no eigenvalue is 0.)

Answer A⁻¹X = (1/λ)X, which says exactly that 1/λ is an eigenvalue of A⁻¹. ■
