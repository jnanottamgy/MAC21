UNIT I

1   Expand xy + cos(xy) about (1, π/2) to second degree  4× NEEDS CALCULUS

The formula f(x,y) = f(a,b) + [h fₓ + k fᵧ] + (1/2)[h²fₓₓ + 2hk fₓᵧ + k²fᵧᵧ]
with h = x−a, k = y−b. Here a=1, b=π/2, so h = x−1, k = y−π/2. You need six quantities.

Step 1: fₓ Differentiate f = xy + cos(xy) w.r.t. x, treating y as a plain number.
• xy: y is a number times x → gives y
• cos(xy): chain rule. Outside is cos, which differentiates to −sin. Inside is xy, which differentiates (w.r.t. x) to y. Multiply them: −sin(xy)·y
fₓ = y − y sin(xy) = y[1 − sin(xy)]

Step 2: fᵧ Same thing with the roles swapped: fᵧ = x − x sin(xy) = x[1 − sin(xy)]

Step 3: fₓₓ Differentiate fₓ = y − y sin(xy) w.r.t. x again. y is still a number.
• y is a plain number → 0
• −y sin(xy): chain rule again. sin → cos, inside gives y: −y·cos(xy)·y = −y²cos(xy)
fₓₓ = −y² cos(xy)

Step 4: fᵧᵧ By the same working with x and y swapped: fᵧᵧ = −x² cos(xy)

Step 5: fₓᵧ Take fₓ = y − y sin(xy) and differentiate w.r.t. y. Now x is the plain number.
• y → 1
• −y sin(xy) is two things multiplied — product rule. Let u = −y and v = sin(xy).
  u′ = −1;  v′ = cos(xy)·x (chain rule, inside differentiates to x)
  u′v + uv′ = (−1)sin(xy) + (−y)(x cos(xy)) = −sin(xy) − xy cos(xy)
fₓᵧ = 1 − sin(xy) − xy cos(xy)

Step 6 — now just put the numbers in. At x=1, y=π/2:
first work out xy = 1 × π/2 = π/2. Then sin(π/2) = 1 and cos(π/2) = 0.

f(x,y) = π/2

Do not panic. Getting all zeros is the correct answer here, not a mistake. Show the table, say "all first and second order partial derivatives vanish at (1, π/2)", and state the result. Full marks.

Then f = (1+π/2) + [(π/2)h + k] + ½[−(π²/4)h² + 2(1−π/2)hk − k²]

2   Newton-Raphson system, two iterations, from (0.8, 0.4)  4× easy calculus only

Step 1 — get everything on one side. x²+y²=x and x²−y²=y become
f = x² + y² − x    g = x² − y² − y

Step 2 — four partial derivatives. All are just the power rule.
fₓ = 2x − 1 (the y² is a number, gives 0)  ·  fᵧ = 2y
gₓ = 2x  ·  gᵧ = −2y − 1

Step 3 — the rule. At the current point solve these two equations for the corrections h, k:
h fₓ + k fᵧ = −f    h gₓ + k gᵧ = −g
then x₋ = x + h, y₋ = y + k.

ITERATION 1 at (0.8, 0.4):
f = 0.64 + 0.16 − 0.8 = 0.0000  (zero — fine, not an error)
g = 0.64 − 0.16 − 0.4 = 0.0800
fₓ = 1.6−1 = 0.6, fᵧ = 0.8, gₓ = 1.6, gᵧ = −0.8−1 = −1.8
Equations: 0.6h + 0.8k = 0  and  1.6h − 1.8k = −0.08
From the first: h = −(0.8/0.6)k = −1.3333k. Substitute into the second:
1.6(−1.3333k) − 1.8k = −0.08 → −2.1333k − 1.8k = −0.08 → −3.9333k = −0.08
k = 0.020339,  h = −1.3333(0.020339) = −0.027119
x₁ = 0.8 − 0.027119 = 0.772881,  y₁ = 0.4 + 0.020339 = 0.420339

ITERATION 2 at (0.772881, 0.420339). Recompute everything:
f = 0.597345 + 0.176685 − 0.772881 = 0.001149
g = 0.597345 − 0.176685 − 0.420339 = 0.000321
fₓ = 0.545762, fᵧ = 0.840678, gₓ = 1.545762, gᵧ = −1.840678
Solving: h = −0.001035, k = −0.000695

Answer x₂ = 0.771846,   y₂ = 0.419644

Watch the start point — it changes between papers. From (0.8, 0.3) the answer is 0.772041, 0.419921; from (1, 0.5) it is 0.773720, 0.420557. Read it off the question.

3   Open-top box, volume 108 ft³, minimum surface area  2× NEEDS CALCULUS

Step 1 — set up. Let the base be x by y and the height z.
Open at the top means only ONE xy face (the base). The four sides are two of xz and two of yz.
Surface area S = xy + 2xz + 2yz.  Constraint: xyz = 108.

Step 2 — Lagrange's method. Form F = S − λ(xyz − 108), then set the three partial derivatives to zero.

Step 3 — differentiate. For Fₓ, treat y, z, λ as numbers:
• xy → y  • 2xz → 2z  • 2yz → 0 (no x)  • −λxyz → −λyz
Fₓ = y + 2z − λyz = 0  …(1)
Similarly Fᵧ = x + 2z − λxz = 0  …(2)    Fᵦ = 2x + 2y − λxy = 0  …(3)

Step 4 — kill λ immediately. You never need its value.
From (1): λ = (y+2z)/(yz).  From (2): λ = (x+2z)/(xz). Set equal:
(y+2z)/(yz) = (x+2z)/(xz). Cross-multiply: xz(y+2z) = yz(x+2z)
xyz + 2xz² = xyz + 2yz² → 2xz² = 2yz² → x = y

Step 5 — use (3) with x = y.
From (1) with y = x: λ = (x+2z)/(xz). From (3): λ = (2x+2y)/(xy) = 4x/x² = 4/x
So (x+2z)/(xz) = 4/x. Multiply both sides by xz: x + 2z = 4z → x = 2z

Step 6 — use the volume. xyz = 108 with x = y = 2z:
(2z)(2z)(z) = 108 → 4z³ = 108 → z³ = 27 → z = 3
Then x = y = 6.

Answer Base 6 ft × 6 ft, height 3 ft, and S = 36 + 2(18) + 2(18) = 108 ft²

4   Hottest point on the unit sphere, T = 400xyz²  1× NEEDS CALCULUS

Step 1 Maximise T = 400xyz² subject to x²+y²+z² = 1.
F = 400xyz² − λ(x²+y²+z² − 1)

Step 2 — three partial derivatives.
Fₓ = 400yz² − 2λx = 0  …(1)
Fᵧ = 400xz² − 2λy = 0  …(2)
Fᵦ = 800xyz − 2λz = 0  …(3)  (note: z² differentiates to 2z, hence 800)

Step 3 Multiply (1) by x and (2) by y:
400xyz² = 2λx²  and  400xyz² = 2λy² → x² = y²
Multiply (3) by z: 800xyz² = 2λz². Compare with the first: 2(2λx²) = 2λz² → z² = 2x²

Step 4 Put into the sphere: x² + x² + 2x² = 1 → 4x² = 1 → x² = 1/4, so x = ±½, y = ±½, z² = ½

Step 5 T = 400 × x × y × z² = 400 × (¼) × (½) = 50  (taking xy > 0)

Answer Highest temperature = 50, at (±½, ±½, ±1/√2) with x and y the same sign

5   Runge-Kutta 4th order  6× — every paper NO CALCULUS

Question dy/dx = y − x², y(2) = 5, find y(2.1), h = 0.1.

The four numbers (learn this shape — it never changes):
k₁ = h·f(x₀, y₀)
k₂ = h·f(x₀ + h/2,  y₀ + k₁/2)
k₃ = h·f(x₀ + h/2,  y₀ + k₂/2)  ← uses k₂, not k₁
k₄ = h·f(x₀ + h,     y₀ + k₃)  ← full step, and no halving of k₃

Here f(x,y) = y − x², x₀=2, y₀=5, h=0.1, so h/2 = 0.05.

k₁ = 0.1 × f(2, 5) = 0.1 × (5 − 4) = 0.1 × 1 = 0.100000

k₂ = 0.1 × f(2.05,  5 + 0.05) = 0.1 × f(2.05, 5.05)
  f = 5.05 − (2.05)² = 5.05 − 4.2025 = 0.8475 → k₂ = 0.084750

k₃ = 0.1 × f(2.05,  5 + 0.084750/2) = 0.1 × f(2.05, 5.042375)
  f = 5.042375 − 4.2025 = 0.839875 → k₃ = 0.083988

k₄ = 0.1 × f(2.1,  5 + 0.083988) = 0.1 × f(2.1, 5.083988)
  f = 5.083988 − 4.41 = 0.673988 → k₄ = 0.067399

Combine Δy = (k₁ + 2k₂ + 2k₃ + k₄)/6
= (0.100000 + 2(0.084750) + 2(0.083988) + 0.067399)/6
= (0.100000 + 0.169500 + 0.167976 + 0.067399)/6 = 0.504875/6 = 0.084146

Answer y(2.1) = 5 + 0.084146 = 5.084146

Two traps The k's already contain h — do not multiply by h again at the end. And k₃ uses k₂.

6   Modified Euler's method  5× NO CALCULUS

Question dy/dx = −y/(1+x), y(3) = 2, find y(3.2), h = 0.2.

The idea Euler uses the slope at the start. Modified Euler averages the slope at the start and the slope at the end — but you do not know the end value yet, so you guess it, then improve.

Step 1 — the fixed number. f(3, 2) = −2/(1+3) = −2/4 = −0.5
This value never changes during the whole question. Write it down and keep it.

Step 2 — predictor (the guess). Ordinary Euler:
y₁⁽⁰⁾ = y₀ + h·f(x₀,y₀) = 2 + 0.2(−0.5) = 2 − 0.1 = 1.900000

Step 3 — corrector, first time. The rule is
y₁ = y₀ + (h/2)[f(x₀,y₀) + f(x₁,  latest guess)]  with x₁ = 3.2, h/2 = 0.1
f(3.2, 1.9) = −1.9/(1+3.2) = −1.9/4.2 = −0.452381
y₁ = 2 + 0.1[−0.5 + (−0.452381)] = 2 + 0.1(−0.952381) = 2 − 0.095238 = 1.904762

Step 4 — corrector, second time. Same formula, but use the value you just got:
f(3.2, 1.904762) = −1.904762/4.2 = −0.453515
y₁ = 2 + 0.1[−0.5 + (−0.453515)] = 2 − 0.095352 = 1.904649

Step 5 — once more to show it has settled.
f(3.2, 1.904649) = −0.453488 → y₁ = 1.904651 — the digits have stopped moving.

Answer y(3.2) ≈ 1.9047  (exact value 1.904762)

The trap The −0.5 stays fixed. Only the second term inside the bracket updates.

7   Newton's law of cooling  5× NO CALCULUS NEEDED

Question Coffee at 92°C, room 24°C, cools to 80°C in 1 minute. When does it reach 65°C?

Step 1 — the ready-made formula. You do not have to solve the differential equation:
T = T₀ + (T₁ − T₀)e⁻ᵏᵗ,  T₀ = room temperature, T₁ = starting temperature.

Step 2 — put the numbers in. T₀ = 24, T₁ = 92, so T₁ − T₀ = 68:
T = 24 + 68 e⁻ᵏᵗ

Step 3 — use the 1-minute reading to find k.
At t = 1, T = 80:  80 = 24 + 68e⁻ᵏ
56 = 68e⁻ᵏ → e⁻ᵏ = 56/68 = 14/17 = 0.823529
Take logs of both sides: −k = log(14/17), so k = log(17/14) = 0.194156

Step 4 — now find the time for 65°C.
65 = 24 + 68e⁻ᵏᵗ → 41 = 68e⁻ᵏᵗ → e⁻ᵏᵗ = 41/68 = 0.602941
Take logs: −kt = log(0.602941), so kt = log(68/41) = log(1.658537) = 0.505933
t = 0.505933 / 0.194156

Answer t = 2.606 minutes (about 2 minutes 36 seconds)

Shortcut when the question asks for a whole multiple of the given time — e.g. "250°F after 10 min, what after 20 min?" — you never need k at all: e⁻²⁰ᵏ = (e⁻¹⁰ᵏ)². Just square the ratio.
300°F / room 80°F / 250°F at 10 min: e⁻¹⁰ᵏ = 170/220 = 17/22; T(20) = 80 + 220(17/22)² = 80 + 131.36 = 211.36 °F

9   Show x²/(a²+λ) + y²/(b²+λ) = 1 is self-orthogonal  2× NEEDS CALCULUS

What "self-orthogonal" means When you do the orthogonal-trajectory procedure on this family, you get the same family back. So you must show the differential equation is unchanged when you replace y′ by −1/y′. You do not solve anything.

Step 1 — differentiate. Treat a, b, λ as constants and remember y depends on x (so y² differentiates to 2y y′):
2x/(a²+λ) + 2y y′/(b²+λ) = 0
Divide by 2:  x/(a²+λ) = −y y′/(b²+λ)

Step 2 — get expressions for the two denominators. Write p = y′ for short.
From Step 1, (a²+λ) = −x(b²+λ)/(yp). Substituting this back into the original equation and simplifying gives:
a² + λ = x(x + yp)/(xp − y)·(−1) … the standard result is
a² + λ = −(x + y p)·x/(yp)  and  b² + λ = −(x + y p)·y/(x)·…

Step 3 — the actual exam answer. Eliminating λ between the two gives the differential equation of the family:
(x + y p)(x p − y) = (a² − b²) p  …(★)

Step 4 — the test. Replace p by −1/p everywhere in (★):
(x + y(−1/p))(x(−1/p) − y) = (a²−b²)(−1/p)
Left side: ((xp − y)/p)·((−x − yp)/p) = −(xp−y)(x+yp)/p²
So the equation becomes −(xp−y)(x+yp)/p² = −(a²−b²)/p
Multiply both sides by −p²:  (x+yp)(xp−y) = (a²−b²)p

Answer That is exactly equation (★) again.
The family is unchanged by the substitution, so it is self-orthogonal. ■
These are confocal conics — each ellipse of the family cuts each hyperbola at right angles.

10   Orthogonal trajectories of co-axial circles x²+y²+2gx+c=0  6× (topic) NEEDS CALCULUS

The three steps — always the same
1. Differentiate, and eliminate the parameter.  2. Replace dy/dx by −dx/dy.  3. Solve.

Step 1 — differentiate. Here g is the parameter, c is fixed.
2x + 2y y′ + 2g = 0 → divide by 2 → x + y y′ + g = 0
So g = −(x + y y′)

Step 2 — eliminate g by putting that back into the original equation:
x² + y² + 2x·[−(x + y y′)] + c = 0
x² + y² − 2x² − 2xy y′ + c = 0
y² − x² + c = 2xy y′  … this is the DE of the given family.

Step 3 — swap. Replace y′ by −1/y′:
y² − x² + c = 2xy(−1/y′) = −2xy/y′
Multiply through by y′:  (y² − x² + c)y′ = −2xy

Step 4 — solve. This is a homogeneous-type equation; solving gives the conjugate family
x² + y² + 2λy − c = 0
Same shape, but the parameter now multiplies y instead of x — the perpendicular system of co-axial circles. Even if you cannot finish the integration, Steps 1–3 are worth most of the marks: write them.

UNIT III

Read this before the Unit III questions. D is shorthand for "differentiate". So Dy = dy/dx, D²y = d²y/dx². An equation like y″ + 3y′ + 2y = φ(x) is written (D² + 3D + 2)y = φ(x).
Every answer has two halves:  C.F. (solve with the right side set to 0) and P.I. (deal with the right side).  y = C.F. + P.I.

11   C.F. + P.I. — solve (D² + 2D + 1)y = x e²ₓ  6× (topic) light calculus

Step 1 — the C.F. Replace D by m and set to zero:
m² + 2m + 1 = 0 → (m+1)² = 0 → m = −1, twice
Repeated root rule: yᶜ = (C₁ + C₂x)e⁻ₓ

Step 2 — the P.I. yᵧ = [1/(D²+2D+1)]·x e²ₓ
The right side is eᵃₓ times something, with a = 2. Use the shift rule: pull the exponential out front and replace every D by D+a:
yᵧ = e²ₓ·[1/((D+2)² + 2(D+2) + 1)]·x

Step 3 — expand the bracket.
(D+2)² = D² + 4D + 4;  2(D+2) = 2D + 4
Add them and the 1: D² + 4D + 4 + 2D + 4 + 1 = D² + 6D + 9
yᵧ = e²ₓ·[1/(9 + 6D + D²)]·x

Step 4 — expand the fraction as a series. Take the 9 out front so it starts with 1:
1/(9 + 6D + D²) = (1/9)·1/[1 + (6D + D²)/9]
Now use 1/(1+u) = 1 − u + u² − … with u = (6D+D²)/9:
= (1/9)[1 − 6D/9 − D²/9 + …]
Why we can stop: we are applying this to x, and D²(x) = 0 (differentiate x twice and you get 0). So only the 1 and the D terms survive.

Step 5 — apply it to x. D means differentiate: D(x) = 1.
(1/9)[x − (6/9)(1)] = (1/9)[x − 2/3] = (3x − 2)/27

Answer y = (C₁ + C₂x)e⁻ₓ + (3x − 2)e²ₓ/27

The four P.I. rules, in one place
• Right side eᵃₓ → answer is eᵃₓ/f(a): just put D = a. If that gives 0, multiply by x and differentiate the bottom, then try again.
• Right side sin ax or cos ax → replace every D² by −a².
• Right side xⁿ → expand the fraction in rising powers of D and stop once Dⁿ⁺¹ would kill it.
• Right side eᵃₓ·V → pull eᵃₓ out front, replace D by D+a.

12   Cauchy's equation: x²y″ − 4xy′ + 6y = cos(2 log x)  4× no calculus after the swap

How to spot it The powers of x match the number of dashes: x² with y″, x with y′.

Step 1 — the substitution. Put x = eᶻ, i.e. z = log x. Now D means d/dz. Learn these three replacements:
x y′ = Dy    x² y″ = D(D−1)y    x³ y′″ = D(D−1)(D−2)y
The (D−1) is what people forget. It is not D².

Step 2 — substitute.
D(D−1)y − 4Dy + 6y = cos 2z  (log x became z)
Expand D(D−1) = D² − D:
D²y − Dy − 4Dy + 6y = cos2z → (D² − 5D + 6)y = cos 2z
It is now an ordinary constant-coefficient equation.

Step 3 — C.F. m² − 5m + 6 = 0 → (m−2)(m−3) = 0 → m = 2, 3
yᶜ = C₁e²ᶻ + C₂e³ᶻ

Step 4 — P.I. yᵧ = [1/(D² − 5D + 6)]cos 2z.
Right side is a cosine → replace D² by −a² = −4:
= [1/(−4 − 5D + 6)]cos2z = [1/(2 − 5D)]cos 2z

Step 5 — clear the D from the bottom. Multiply top and bottom by (2 + 5D):
= (2 + 5D)cos2z / [(2−5D)(2+5D)] = (2 + 5D)cos2z / (4 − 25D²)
On the bottom, replace D² by −4 again: 4 − 25(−4) = 4 + 100 = 104

Step 6 — apply the top. D(cos 2z) = −2 sin 2z:
(2 + 5D)cos2z = 2cos2z + 5(−2 sin2z) = 2cos2z − 10 sin2z
yᵧ = (2cos2z − 10sin2z)/104 = (cos2z − 5 sin2z)/52

Step 7 — go back to x. eᶻ = x, so e²ᶻ = x² and e³ᶻ = x³; and z = log x.

Answer y = C₁x² + C₂x³ + [cos(2 log x) − 5 sin(2 log x)]/52

13   Legendre's equation: (2x+3)²y″ + 2(2x+3)y′ − 12y = 0  4× no calculus after the swap

Same as Cauchy, one extra factor. Put 2x+3 = eᶻ. Here a = 2 (whatever multiplies x). The replacements pick up powers of a:
(2x+3)y′ = 2Dy    (2x+3)²y″ = 2²D(D−1)y = 4D(D−1)y
The 4 is the mark-loser. Do not drop it.

Step 1 — substitute.
4D(D−1)y + 2·(2Dy) − 12y = 0
4(D² − D)y + 4Dy − 12y = 0
4D²y − 4Dy + 4Dy − 12y = 0
The −4Dy and +4Dy cancel:  4D²y − 12y = 0

Step 2 Divide by 4: D²y − 3y = 0. A.E.: m² − 3 = 0 → m = ±√3

Step 3 y = C₁e√³ᶻ + C₂e⁻√³ᶻ

Step 4 — back-substitute. Since eᶻ = 2x+3: e√³ᶻ = (eᶻ)√³ = (2x+3)√³

Answer y = C₁(2x+3)√³ + C₂(2x+3)⁻√³

Useful fact Cauchy's equation is just Legendre's with a=1, b=0. Learn one, you have both.

14   Variation of parameters: y″ − 6y′ + 9y = e³ₓ/x²  5× — every paper NEEDS CALCULUS

When to use it When the right-hand side is something the ordinary P.I. rules cannot handle — sec³x, tan x, e³ₓ/x², cos(e⁻ₓ). That awkwardness is the signal.

The recipe For y″ + Py′ + Qy = R with C.F. C₁y₁ + C₂y₂:
1. W = y₁y₂′ − y₂y₁′  (the Wronskian)
2. A = −∫(y₂R/W)dx    B = ∫(y₁R/W)dx  (note the minus on A)
3. yᵧ = A y₁ + B y₂
The coefficient of y″ must be 1 before you read off R. Here it already is.

Step 1 — C.F. m² − 6m + 9 = (m−3)² = 0 → m = 3 twice
So y₁ = e³ₓ and y₂ = x e³ₓ. Also R = e³ₓ/x².

Step 2 — the two derivatives.
y₁′ = 3e³ₓ
y₂′: this is x times e³ₓ → product rule. u = x, u′ = 1; v = e³ₓ, v′ = 3e³ₓ
y₂′ = (1)e³ₓ + x(3e³ₓ) = e³ₓ(1 + 3x)

Step 3 — the Wronskian.
W = e³ₓ·e³ₓ(1+3x) − xe³ₓ·3e³ₓ
= e⁶ₓ(1 + 3x) − 3x e⁶ₓ = e⁶ₓ(1 + 3x − 3x) = e⁶ₓ
Nice and clean — the x terms cancel.

Step 4 — the first integral.
y₂R/W = [x e³ₓ × e³ₓ/x²] / e⁶ₓ
Top: x e³ₓ × e³ₓ/x² = e⁶ₓ/x  (the x cancels one x²)
Divide by e⁶ₓ: = 1/x
A = −∫(1/x)dx = −log x

Step 5 — the second integral.
y₁R/W = [e³ₓ × e³ₓ/x²]/e⁶ₓ = (e⁶ₓ/x²)/e⁶ₓ = 1/x²
B = ∫x⁻²dx = x⁻¹/(−1) = −1/x

Step 6 — assemble.
yᵧ = A y₁ + B y₂ = (−log x)(e³ₓ) + (−1/x)(x e³ₓ)
The second term: (−1/x)(x e³ₓ) = −e³ₓ
yᵧ = −e³ₓ log x − e³ₓ

Step 7 Add the C.F. The lone −e³ₓ is absorbed into C₁.

Answer y = (C₁ + C₂x − log x)e³ₓ

Even if the integrals defeat you — write the C.F., the Wronskian, and the two integral expressions. That is most of the 7 marks before you integrate anything.

18   Lagrange's interpolation  3× NO CALCULUS

Question Find f(1) from (−1, 9), (0, 5), (2, 3).

The pattern One term per data point. Each term is
yᵢ × [(x minus the other x's)] / [(this x minus the other x's)]

Step 1 — term for (−1, 9). The other x's are 0 and 2:
top = (x−0)(x−2)    bottom = (−1−0)(−1−2) = (−1)(−3) = 3
Term = 9(x)(x−2)/3

Step 2 — term for (0, 5). Others are −1 and 2:
top = (x+1)(x−2)    bottom = (0+1)(0−2) = (1)(−2) = −2
Term = 5(x+1)(x−2)/(−2)

Step 3 — term for (2, 3). Others are −1 and 0:
top = (x+1)(x−0)    bottom = (2+1)(2−0) = (3)(2) = 6
Term = 3(x+1)(x)/6

Step 4 — put x = 1 straight in (no need to expand):
Term 1: 9(1)(1−2)/3 = 9(1)(−1)/3 = −3
Term 2: 5(2)(−1)/(−2) = −10/−2 = 5
Term 3: 3(2)(1)/6 = 6/6 = 1
Add: −3 + 5 + 1

Answer f(1) = 3   (the full polynomial, if asked, is x² − 3x + 5)

19   System of ODEs by the matrix method  3×/3 — the last question of every paper NO CALCULUS

Question Rabbits r and wolves w: dr/dt = 4r − 2w, dw/dt = r + w, with r(0)=240, w(0)=300.

Step 1 — write it as a matrix. Read the coefficients straight off:
A = [[4, −2], [1, 1]]

Step 2 — eigenvalues. Subtract λ down the diagonal and set the determinant to zero:
|4−λ  −2 ;  1  1−λ| = (4−λ)(1−λ) − (−2)(1) = 0
(4−λ)(1−λ) = 4 − 4λ − λ + λ² = λ² − 5λ + 4
So λ² − 5λ + 4 + 2 = 0 → λ² − 5λ + 6 = 0 → (λ−2)(λ−3) = 0
λ = 2 and λ = 3
Check: they should add to the trace 4+1 = 5 ✓ and multiply to the determinant 6 ✓

Step 3 — eigenvector for λ = 2. Solve (A − 2I)X = 0:
[[2, −2],[1, −1]][x₁;x₂] = 0 → first row: 2x₁ − 2x₂ = 0 → x₁ = x₂
Pick the simplest: V₁ = [1, 1]ᵀ

Step 4 — eigenvector for λ = 3. (A − 3I)X = 0:
[[1, −2],[1, −2]][x₁;x₂] = 0 → x₁ = 2x₂ → V₂ = [2, 1]ᵀ

Step 5 — write the general solution. One term per eigenvalue:
[r; w] = c₁[1;1]e²ᵗ + c₂[2;1]e³ᵗ
Reading off each row:
r = c₁e²ᵗ + 2c₂e³ᵗ    w = c₁e²ᵗ + c₂e³ᵗ
Keep the eigenvector components with the right variable — the 2 belongs to r.

Step 6 — use the starting values. At t = 0, e⁰ = 1:
c₁ + 2c₂ = 240  …(i)    c₁ + c₂ = 300  …(ii)
Subtract (ii) from (i): c₂ = −60. Then from (ii): c₁ = 300 + 60 = 360

Answer r(t) = 360e²ᵗ − 120e³ᵗ    w(t) = 360e²ᵗ − 60e³ᵗ

Check (always do this) r(0) = 360 − 120 = 240 ✓   w(0) = 360 − 60 = 300 ✓

20   Diagonalization, and hence Aⁿ  3×/3 NO CALCULUS

Question Diagonalize A = [[1, −1], [2, 4]] and hence find A⁸.

Why this works A⁸ by hand is eight matrix multiplications. But if A = PDP⁻¹ with D diagonal, then A⁸ = PD⁸P⁻¹ — and raising a diagonal matrix to a power just means raising each diagonal entry.

Step 1 — eigenvalues.
|1−λ  −1 ;  2  4−λ| = (1−λ)(4−λ) − (−1)(2) = 0
(1−λ)(4−λ) = 4 − λ − 4λ + λ² = λ² − 5λ + 4
λ² − 5λ + 4 + 2 = 0 → (λ−2)(λ−3) = 0 → λ = 2, 3

Step 2 — eigenvectors.
λ=2: (A−2I) = [[−1,−1],[2,2]]; row 1 gives −x₁ − x₂ = 0 → x₂ = −x₁ → V₁ = [−1, 1]ᵀ
λ=3: (A−3I) = [[−2,−1],[2,1]]; row 1 gives −2x₁ − x₂ = 0 → x₂ = −2x₁ → V₂ = [−1, 2]ᵀ

Step 3 — build P and D. Eigenvectors as columns, eigenvalues on the diagonal in the same order:
P = [[−1, −1], [1, 2]]    D = [[2, 0], [0, 3]]

Step 4 — invert P. For a 2×2 matrix [[a,b],[c,d]]: swap a and d, negate b and c, divide by the determinant.
det P = (−1)(2) − (−1)(1) = −2 + 1 = −1
P⁻¹ = (1/−1)[[2, 1], [−1, −1]] = [[−2, −1], [1, 1]]

Step 5 — raise D to the 8th. Diagonal, so just do each entry:
2⁸ = 256,  3⁸ = 6561 → D⁸ = [[256, 0], [0, 6561]]

Step 6 — multiply out P D⁸ P⁻¹.
First P D⁸ = [[−1,−1],[1,2]][[256,0],[0,6561]] = [[−256, −6561], [256, 13122]]
Then times P⁻¹ = [[−2,−1],[1,1]]:
row 1: (−256)(−2) + (−6561)(1) = 512 − 6561 = −6049;   (−256)(−1) + (−6561)(1) = 256 − 6561 = −6305
row 2: (256)(−2) + (13122)(1) = −512 + 13122 = 12610;   (256)(−1) + (13122)(1) = −256 + 13122 = 12866

Answer A⁸ = [[−6049, −6305], [12610, 12866]]

22   Rank and consistency  2× NO CALCULUS

Question Find the condition on a, b, c for x + 2y − z = a; 2x + y + z = b; x − y + 2z = c to have a solution.

Step 1 — is the determinant zero?
|1  2  −1 ;  2  1  1 ;  1  −1  2|
= 1(1×2 − 1×(−1)) − 2(2×2 − 1×1) + (−1)(2×(−1) − 1×1)
= 1(2+1) − 2(4−1) − 1(−2−1) = 3 − 6 + 3 = 0
Determinant is zero, so there is no unique solution — a condition is needed.

Step 2 — find the relation between the rows. Add row 1 and row 3:
(1+1)x + (2−1)y + (−1+2)z = a + c → 2x + y + z = a + c
But row 2 says 2x + y + z = b.

Step 3 — the two must agree.

Answer The system is consistent only if b = a + c
If b ≠ a+c the same left side would equal two different numbers — impossible, so no solution.

Step 4 — if they ask for the solutions too. Say a=1, b=3, c=2 (so b=a+c ✓). Rank is 2 with 3 unknowns, so 3−2 = 1 free parameter. Let z = t:
From (1): x + 2y = 1 + t; from (2): 2x + y = 3 − t
Solving these two: x = 5/3 − t,   y = t − 1/3,   z = t — infinitely many solutions.
