UNIT I  —  Series Expansion, Newton-Raphson, Maxima–Minima

1Write Taylor's series for a function of one variable f(x) = f(a) + (x−a)f′(a)/1! + (x−a)²f″(a)/2! + … + (x−a)ⁿfⁿ(a)/n! + …  (about the point x = a)1×
2Write Maclaurin's series for a function of one variable f(x) = f(0) + x f′(0)/1! + x²f″(0)/2! + x³f′″(0)/3! + …  (Taylor's series about x = 0)2×
3State Taylor's series for two variables f(x,y) = f(a,b) + [h fₓ + k fᵧ] + (1/2!)[h²fₓₓ + 2hk fₓᵧ + k²fᵧᵧ] + …
where h = x−a, k = y−b, all derivatives evaluated at (a,b).		2×
4State Maclaurin's series for two variables Same as above with a = b = 0: f(x,y) = f(0,0) + [x fₓ + y fᵧ] + (1/2!)[x²fₓₓ + 2xy fₓᵧ + y²fᵧᵧ] + …, derivatives at (0,0).LIKELY
5Define algebraic and transcendental equations, with an example each Algebraic: contains only algebraic terms — powers of x. e.g. x³ − x² + 9 = 0.
Transcendental: contains exponential, logarithmic or trigonometric terms. e.g. x eₓ − 9 = 0, x sin x + log x = 0.		2×
6Write the Newton-Raphson iteration formula xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ),  n = 0, 1, 2, …LIKELY
7Geometrical interpretation of Newton-Raphson Draw the tangent to y = f(x) at the point (xₙ, f(xₙ)). The point where that tangent cuts the x-axis is the next approximation xₙ₊₁. Repeating drives the point towards the root.2×
8Explain N-R for a system of non-linear simultaneous equations For f(x,y)=0, g(x,y)=0: at (x₀,y₀) solve the linear pair
−f = h fₓ + k fᵧ,  −g = h gₓ + k gᵧ
for the corrections h, k; then x₁ = x₀+h, y₁ = y₀+k. Repeat.		1×
9Can N-R find a root of x e⁻ₓ = 0 near x = 2? Justify No. f(x) = x e⁻ₓ has f′(x) = e⁻ₓ(1−x), which is zero at x = 1 and very small near x = 2. The iteration divides by f′, so it diverges. N-R fails when f′ is zero or near zero at the starting point.1×
10State the intermediate value property (how to locate a root) If f is continuous on [a,b] and f(a), f(b) have opposite signs, then f(x)=0 has at least one real root c in (a,b).LIKELY
11Define maxima and minima for a function of two variables f(a,b) is a maximum if f(a+h, b+k) < f(a,b) for all small h,k; a minimum if f(a+h,b+k) > f(a,b). Both are local (relative) extrema.1×
12State the working rule (r-s-t test) for extrema of f(x,y) Solve fₓ=0, fᵧ=0 for stationary points. Put r=fₓₓ, s=fₓᵧ, t=fᵧᵧ.
rt−s²>0, r<0 → maximum · rt−s²>0, r>0 → minimum · rt−s²<0 → saddle point · rt−s²=0 → test fails.		LIKELY
13Define a saddle point A stationary point that is neither a maximum nor a minimum — the function increases along one direction and decreases along another. Occurs when rt − s² < 0.LIKELY
14State Lagrange's method of undetermined multipliers To find extrema of u(x,y,z) subject to φ(x,y,z) = 0, form F = u + λφ and solve Fₓ = 0, Fᵧ = 0, Fᵦ = 0 together with φ = 0. λ is the undetermined multiplier.LIKELY
15Write two differences between analytical and numerical methods Analytical: gives an exact closed-form solution; applies only to a limited class of equations.
Numerical: gives an approximate solution to a stated accuracy; applies to almost any equation, and is iterative/computational.		1×

UNIT II  —  First Order ODEs, Applications, Numerical Solution

#QuestionAnswerSeen
16Define orthogonal trajectories Two families of curves such that every member of one family cuts every member of the other at right angles. Each family is the orthogonal trajectory of the other.2×
17Steps to find orthogonal trajectories of f(x,y,c)=0 (Cartesian) 1. Differentiate w.r.t. x and eliminate the parameter c to get the family's DE.
2. Replace dy/dx by −dx/dy.
3. Solve the resulting DE — that is the orthogonal family.		1×
18Steps for orthogonal trajectories in polar form 1. Differentiate f(r,θ,c)=0 w.r.t. θ and eliminate c.
2. Replace dr/dθ by −r²(dθ/dr).
3. Solve the resulting DE.		1×
19Write the integrating factor for a linear first-order DE For dy/dx + P(x)·y = Q(x):  I.F. = e∫᱿ᵈᵄ, and the solution is y·(I.F.) = ∫ Q·(I.F.) dx + c.LIKELY
20Write the DE of an L–R circuit L (di/dt) + R i = E  →  di/dt + (R/L) i = E/LLIKELY
21Write the DE of an R–C circuit with source E R (dq/dt) + q/C = E  →  dq/dt + q/(CR) = E/R,  with i = dq/dt.1×
22Write the DE of a closed L–C circuit in series, no applied e.m.f. L (d²q/dt²) + q/C = 0  (no resistance, no source — simple harmonic)2×
23Write the DE of an L–C–R circuit L (di/dt) + R i + q/C = E  →  di/dt + (R/L) i + q/(LC) = E/LLIKELY
24State Newton's law of cooling The rate of change of temperature of a body is proportional to the difference between its temperature and that of the surrounding medium: dT/dt = −k(T − T₀), giving T = T₀ + (T₁ − T₀)e⁻ᵏᵗ.LIKELY
25Write Euler's formula to solve a first order, first degree ODE For dy/dx = f(x,y), y(x₀) = y₀:  yₙ₊₁ = yₙ + h·f(xₙ, yₙ),  h = step length.2×
26Write the modified Euler formula Predictor: yₙ₊₁⁽⁰⁾ = yₙ + h f(xₙ, yₙ)
Corrector: yₙ₊₁⁽ᵏ⁺¹⁾ = yₙ + (h/2)[f(xₙ,yₙ) + f(xₙ₊₁, yₙ₊₁⁽ᵏ⁾)], iterated until it settles.		LIKELY
27Write the Runge-Kutta formula of fourth order k₁ = h f(x₀, y₀) · k₂ = h f(x₀+h/2, y₀+k₁/2) · k₃ = h f(x₀+h/2, y₀+k₂/2) · k₄ = h f(x₀+h, y₀+k₃)
y₁ = y₀ + (1/6)(k₁ + 2k₂ + 2k₃ + k₄)		1×
28Write the Taylor's series method formula for an ODE y(x) = y₀ + (x−x₀)y′₀/1! + (x−x₀)²y″₀/2! + (x−x₀)³y′″₀/3! + …
Derivatives are found by repeatedly differentiating y′ = f(x,y) and evaluating at (x₀, y₀).		LIKELY

UNIT III  —  Linear Differential Equations of Higher Order

#QuestionAnswerSeen
29Define linear and non-linear differential equations, with examples Linear: the dependent variable and all its derivatives occur only in the first degree, and no products of them appear. e.g. y″ + 3y′ + 2y = eₓ.
Non-linear: any other — a power, product, or non-linear function of y or its derivatives. e.g. y″ + y² = 0 or y y′ = x.		3×
30Define a non-homogeneous LDE of second order, with an example A second-order linear DE whose right-hand side is not zero: a₀y″ + a₁y′ + a₂y = φ(x) with φ(x) ≠ 0. e.g. y″ + 4y′ + 4y = e²ₓ. (If φ(x) = 0 it is homogeneous.)1×
31Define complementary function and particular integral C.F. = the general solution of the homogeneous equation f(D)y = 0, carrying the arbitrary constants.
P.I. = any one solution of f(D)y = φ(x), given by (1/f(D))φ(x). Complete solution y = C.F. + P.I.		LIKELY
32Write the C.F. if the roots of the A.E. are −3±i, 2, 2, 2 yᶜ = e⁻³ₓ(C₁cos x + C₂sin x) + (C₃ + C₄x + C₅x²)e²ₓ1×
33Write the C.F. of a 4th-order LDE if two roots are imaginary and two are real and distinct Roots α±iβ, m₁, m₂:
yᶜ = eᴺₓ(C₁cos βx + C₂sin βx) + C₃eᵐ¹ₓ + C₄eᵐ²ₓ		1×
34Rules for the C.F. from the roots (general) Real distinct m₁,m₂ → C₁eᵐ¹ₓ+C₂eᵐ²ₓ · repeated m (k times) → (C₁+C₂x+…+Cᵏxᵏ⁻¹)eᵐₓ · complex α±iβ → eᴺₓ(C₁cosβx + C₂sinβx).LIKELY
35Write the steps for solving Cauchy's LDE 1. Put x = eᶻ, i.e. z = log x; write D = d/dz.
2. Use x y′ = Dy, x²y″ = D(D−1)y, x³y′″ = D(D−1)(D−2)y.
3. The equation becomes constant-coefficient in z — find C.F. and P.I.
4. Substitute back z = log x.		2×
36Write the steps for solving Legendre's LDE Same as Cauchy's, but put ax + b = eᶻ and use
(ax+b)y′ = aDy, (ax+b)²y″ = a²D(D−1)y, (ax+b)³y′″ = a³D(D−1)(D−2)y.
Cauchy's is the special case a=1, b=0.		LIKELY
37Write the steps for the method of variation of parameters 1. Put the equation in standard form y″ + Py′ + Qy = R and find the C.F. C₁y₁ + C₂y₂.
2. Compute the Wronskian W = y₁y₂′ − y₂y₁′.
3. yᵧ = −y₁∫(y₂R/W)dx + y₂∫(y₁R/W)dx.  4. y = C.F. + yᵧ.		1×
38Define an initial value problem A DE together with conditions on the unknown function and its derivatives all specified at one and the same value of the independent variable. e.g. y″+2y′+y=0, y(0)=1, y′(0)=2.LIKELY
39Define a boundary value problem, with an example A DE with conditions specified at two or more different values of the independent variable. e.g. y″ + y = 0, y(0)=2, y(π/2)=−2.2×
40Write the P.I. rule for eᵃₓ (1/f(D))eᵃₓ = eᵃₓ/f(a), provided f(a) ≠ 0.
If f(a)=0, multiply by x and differentiate the denominator: x eᵃₓ/f′(a); repeat if needed.		LIKELY
41Write the P.I. rule for sin ax or cos ax In (1/f(D²)) replace D² by −a². If the denominator becomes zero, multiply by x and differentiate the denominator.LIKELY
42Write the exponential shift rule (P.I. for eᵃₓV(x)) (1/f(D))·eᵃₓV(x) = eᵃₓ·(1/f(D+a))·V(x)
Every D becomes D+a — this is the step most often got wrong.		LIKELY
43If D = d/dx, prove (1/(D+a))X = e⁻ᵃₓ∫Xeᵃₓdx Let y = (1/(D+a))X, so (D+a)y = X, i.e. y′ + ay = X.
This is linear with I.F. eᵃₓ: (y eᵃₓ)′ = X eᵃₓ.
Integrating, y eᵃₓ = ∫X eᵃₓ dx, hence y = e⁻ᵃₓ∫X eᵃₓ dx. ■ (Usually a 4-marker — appeared 4×.)		4×

UNIT IV  —  Interpolation, Numerical Differentiation & Integration

#QuestionAnswerSeen
44Define forward and backward difference, with an example Forward: Δyₙ = yₙ₊₁ − yₙ.  Backward: ∇yₙ = yₙ − yₙ₋₁.
e.g. for y = 2, 5, 10: Δy₀ = 3, Δy₁ = 5; ∇y₂ = 5.		1×
45Obtain Δ²yₙ in terms of y values Δ²yₙ = Δ(Δyₙ) = Δ(yₙ₊₁ − yₙ) = (yₙ₊₂ − yₙ₊₁) − (yₙ₊₁ − yₙ)
∴ Δ²yₙ = yₙ₊₂ − 2yₙ₊₁ + yₙ		2×
46Obtain ∇²yₙ in terms of y values ∇²yₙ = yₙ − 2yₙ₋₁ + yₙ₋₂1×
47Define the shift operator E and its relation to Δ and ∇ E yₙ = yₙ₊₁. Then Δ = E − 1 and ∇ = 1 − E⁻¹, so E = 1 + Δ.LIKELY
48Determine Δ²y₂ and Δ³y₁ from y = 0.0567, 1.2345, 1.5678, 1.0023, 1.786  (a rare calculation) Δ: 1.1778, 0.3333, −0.5655, 0.7837
Δ²: −0.8445, −0.8988, 1.3492   Δ³: −0.0543, 2.2480
Δ²y₂ = −0.8988,  Δ³y₁ = −0.0543		1×
49Write Newton-Gregory forward interpolation formula y = y₀ + pΔy₀ + p(p−1)/2!·Δ²y₀ + p(p−1)(p−2)/3!·Δ³y₀ + …, where p = (x − x₀)/h.LIKELY
50Write Newton-Gregory backward interpolation formula y = yₙ + p∇yₙ + p(p+1)/2!·∇²yₙ + p(p+1)(p+2)/3!·∇³yₙ + …, where p = (x − xₙ)/h.LIKELY
51Write the formula for y′(x) and y″(x) using Newton-Gregory forward dy/dx = (1/h)[Δy₀ + (2p−1)/2·Δ²y₀ + (3p²−6p+2)/6·Δ³y₀ + …]
d²y/dx² = (1/h²)[Δ²y₀ + (p−1)Δ³y₀ + (12p²−36p+22)/24·Δ⁴y₀ + …]
At x = x₀ (p=0): y′ = (1/h)[Δy₀ − Δ²y₀/2 + Δ³y₀/3 − …]		2×
52Write Lagrange's interpolation formula y = Σᵢ yᵢ · Πⱼ≠ᵢ (x − xⱼ)/(xᵢ − xⱼ)  — valid for unequally spaced data.LIKELY
53Write Lagrange's inverse interpolation formula for two points x = x₀(y − y₁)/(y₀ − y₁) + x₁(y − y₀)/(y₁ − y₀)
Same formula with the roles of x and y interchanged.		2×
54Write Newton's divided difference formula y = y₀ + (x−x₀)f[x₀,x₁] + (x−x₀)(x−x₁)f[x₀,x₁,x₂] + …
where f[x₀,x₁] = (y₁−y₀)/(x₁−x₀) and f[x₀,x₁,x₂] = (f[x₁,x₂] − f[x₀,x₁])/(x₂−x₀).		LIKELY
55Find the first order divided difference of x₀=1, x₁=2 if y = x³+4x+3  (a rare calculation) y(1) = 1+4+3 = 8,  y(2) = 8+8+3 = 19
f[x₀,x₁] = (19 − 8)/(2 − 1) = 11		1×
56Write the trapezoidal rule ∫ y dx = (h/2)[(y₀ + yₙ) + 2(y₁ + y₂ + … + yₙ₋₁)]  — any number of intervals.LIKELY
57Write Simpson's 1/3rd rule ∫ y dx = (h/3)[(y₀ + yₙ) + 4(y₁+y₃+y₅+…) + 2(y₂+y₄+y₆+…)]
Requires n to be even.		2×
58Write Simpson's 3/8th rule ∫ y dx = (3h/8)[(y₀ + yₙ) + 3(y₁+y₂+y₄+y₅+…) + 2(y₃+y₆+…)]
Requires n to be a multiple of 3. The 2 multiplies every third ordinate.		LIKELY
59State the Newton-Cotes quadrature formula The general formula obtained by integrating Newton's forward interpolation polynomial over [x₀, x₀+nh]. Trapezoidal (n=1), Simpson's 1/3 (n=2) and Simpson's 3/8 (n=3) are its special cases.LIKELY
60Relation between ordinates and intervals Number of intervals n = number of ordinates − 1. e.g. "seven equidistant ordinates" means n = 6, and h = (b−a)/n.LIKELY

UNIT V  —  Linear Algebra

#QuestionAnswerSeen
61Define row echelon form of a matrix A matrix is in row echelon form if: (i) all zero rows are below every non-zero row; (ii) the first non-zero entry of each row (the leading entry) lies strictly to the right of the leading entry of the row above.1×
62Define the rank of a matrix The number of non-zero rows when the matrix is reduced to echelon form — equivalently the order of its largest non-vanishing minor. Denoted ρ(A), and ρ(A) = ρ(Aᵀ).1×
63Write the conditions for consistency and inconsistency of AX = B Consistent if ρ(A) = ρ(A|B):
  • = n (number of unknowns) → unique solution
  • = r < n → infinitely many, with n−r free parameters
Inconsistent (no solution) if ρ(A) ≠ ρ(A|B).		1×
64Geometrical interpretation of infinitely many solutions for 2x+y=3, 4x+2y=6 The second equation is exactly twice the first, so both represent the same straight line. The lines coincide, so every point on the line is a solution — hence infinitely many.2×
65Geometrical interpretation of a unique solution / no solution Unique: the lines intersect at exactly one point.  No solution: the lines are parallel and distinct — they never meet.LIKELY
66Define elementary row transformations (i) Interchange two rows; (ii) multiply a row by a non-zero scalar; (iii) add a multiple of one row to another. They do not change the rank.LIKELY
67Trivial and non-trivial solutions of AX = 0 Trivial: X = 0, which always exists.
Non-trivial solutions exist only if |A| = 0, i.e. ρ(A) < n.		LIKELY
68Define eigenvalue and eigenvector For a square matrix A, if there is a scalar λ and a non-zero vector X with AX = λX, then λ is an eigenvalue of A and X the corresponding eigenvector.LIKELY
69Write the characteristic equation |A − λI| = 0. Its roots are the eigenvalues.
Note: the eigenvector then comes from (A − λI)X = 0 — a different equation.		LIKELY
70Two properties of eigenvalues Sum of the eigenvalues = trace of A; product of the eigenvalues = |A|. Also: A and Aᵀ have the same eigenvalues, and if λ is an eigenvalue of A then 1/λ is one of A⁻¹.LIKELY
71Define modal and spectral matrix Modal matrix P: the matrix whose columns are the eigenvectors of A — it diagonalizes A.
Spectral matrix D: the resulting diagonal matrix, whose diagonal entries are the eigenvalues in the same order.		1×
72Define similarity transformation If P is non-singular, P⁻¹AP = D is a similarity transformation. Similar matrices have the same eigenvalues.LIKELY
73Is every square matrix diagonalizable? Justify No. An n×n matrix is diagonalizable only if it has n linearly independent eigenvectors. A repeated eigenvalue may not supply enough of them — e.g. [[1,1],[0,1]] has λ=1 twice but only one independent eigenvector, so it is not diagonalizable.1×
74What does Rayleigh's power method determine? The numerically largest (dominant) eigenvalue of a square matrix, and its corresponding eigenvector, by repeatedly forming Y = AX and normalising by the largest component.LIKELY
75State the condition for convergence of Gauss-Seidel (diagonal dominance) In each row the magnitude of the diagonal element must be at least the sum of the magnitudes of the other elements in that row: |aᵢᵢ| ≥ Σⱼ≠ᵢ|aᵢⱼ|. Reorder the equations to achieve this before iterating.LIKELY
76Difference between Gauss elimination and Gauss-Seidel Gauss elimination is a direct method — row-reduce to triangular form and back-substitute, giving the exact solution in finitely many steps.
Gauss-Seidel is an iterative method — start from a guess and refine repeatedly; needs diagonal dominance to converge.		LIKELY
